# 对局笔记重做（设计稿，2026-11-16）

界面按已选定的「合并版」：https://claude.ai/artifact/L67RY5ZaL6F5WceNGwBqbp 最上面一排三屏。这份设计稿说数据怎么存、两种场景怎么接、分几步做。

**状态（2026-11-16）**：两步都已做完。第一步「面杀可用」：四个纯函数模块（`model` / `board` / `votes` / `list`）、`NotesBoard.vue`、新笔记页、列表和新建。第二步「接进法官房间」：`sync.js`（公开信息自动记）、`speech.js`（发言快捷条）、`saver.js`（保存节奏，两处共用）、房间页顶栏「笔记」入口、夜里换步自动收起、再进房间取回笔记；在本地真打一局验过。联调脚本里让机器人开笔记这一项没做，私密信息进不了笔记由 `notes-sync` 的单测盯着。

## 1. 要做成什么

一套笔记，两种场景：

- **平时面杀**：从「笔记」页新建，选板子或只填人数，全部自己点。
- **电子法官房间里**：房间页右上角多一个「笔记」，拉起来就是同一套界面；出局、警长、票型、当前发言人这些全场都看得到的信息自动记，自己只点判断。

两个要求：对局中记得快（几乎不打字），记了一眼看得见。

## 2. 界面（和设计稿一致）

- **主屏：座位盘**。一个座位一个号码块，号码都在左上角：没标过的底色安静（法官房间里多头像和昵称），标了才按「我猜他是」整块上色（狼红、好人绿、神职金），显示「狼 / 好 / 神」、他说自己是什么（对跳标红）和这一天的标记小格（站 3 / 踩 9 / 金 5 / 杀 12 / 划水，最多两格，放不下收成 +N；出局的显示怎么出局的）。警长和「我」是号码块上边的圆徽标。下面是自动汇总的「我的狼坑」和「今天我的判断」。
- **按天切换**：只有「第 N 天」，没有单独的夜晚页。夜里出局的记在天亮的那一天；每天顶上一行说昨夜谁出局、警长是谁（往回翻到前几天时只说那天谁当选，不拿现在的警长说当时），面杀时昨夜还没记会提醒，没人夜里出局时旁边可以点「平安夜」。面杀点「+ 下一天」加一天。
- **点座位**：弹出半屏面板，三组按钮（我猜他是 / 他说自己是 / 这一天他），面杀时多一排状态（夜里出局 / 被放逐 / 被带走 / 自爆 / 当警长）。点了马上生效，不用保存，面板底下是「完成」。点「站边 / 踩人 / 报金水 / 报查杀」后，面板换成一排圆形号码（所有座位，包括他自己；边框是你标的颜色，出局的变淡），直接点号码，不用滚回上面点座位。点开的座位要是被面板挡住，那一排会自动滚到面板上方，面板收起再滚回去。
- **发言快捷条**（只在法官房间里、有人发言时）：显示当前发言人，点「站 X / 踩 X / 跳身份 / 划水 / 写一句」直接记到他的座位上。X 是你已经标了「他说自己是什么」的座位，最多三个；一个都没标时是「站边… / 踩人…」，点了再点座位选人。
- **副屏：票型**。每天一张卡，和法官房间「记录」同一个画法：被投的人一行（圆形头像 + 票条 + 票数，票条按最高票的比例画），下面一排是投他的人；弃票的人单独一排。圆形头像的边框颜色就是你在座位上标的（狼红 / 好人绿 / 神职金）；房间里是头像加右下角圆形号码，面杀没有头像，圆圈里直接是号码。同一组里你标的狼够多时提示一句。那一天有警长竞选的，卡里先显示竞选（上警的人一排，退水的变淡、当选的左上角一个「警」；每人得了谁的票；谁当选 / 警徽流失），再显示放逐投票。面杀时用两步记票：先点被投的人，再点投他的人；放逐票警长算 1.5 票，警长竞选一人一票、最高票记成警长。票数按投票当时记下，之后警徽换人不变。

## 3. 数据怎么存：不改后端

现有接口 `/api/user/sessions` 一条笔记 = 一行会话 + 若干条记录（类型、第几天、玩家、内容 ≤ 5000 字），整份保存。记录类型后端不限制。**新笔记就存成一组新类型的记录**，内容是 JSON，后端和库都不用动，只发小程序就能上线：

| 类型 | 第几天 | 玩家 | 内容 |
|---|---|---|---|
| `n2.meta` | 1 | — | `{"v":2,"days":2,"roomId":"..."}`：版本、记到第几天、关联的法官房间（面杀没有） |
| `n2.seat` | 1 | 座位号 | `{"guess":"wolf","claim":"预言家","name":"团子","out":"exile","outDay":1,"sheriff":true}`：整局不变的标记，一个座位一条 |
| `n2.say` | 那一天 | 座位号 | `{"tags":["站 3","踩 9"],"text":"…"}`：那天他的发言摘要 |
| `n2.day` | 那一天 | — | `{"dead":[7],"votes":[{"target":5,"voters":[1,3,6]}],"abstain":[2],"exiled":5,"judgment":"…","peace":false,"election":{"up":[3,5,9],"off":[9],"votes":[…],"elected":3,"lost":false}}`：那天的死讯、票型（每组带当时的票数 `weight`）、我的判断，这一天之前那一夜是不是平安夜，以及这一天的警长竞选 |

- 没登录时照旧只存在本机，登录后合并上云（沿用现有逻辑）。
- 保存：每次点完先改本机状态，画面立刻变；0.8 秒内没有新操作再整份保存一次。
- 没有 `n2.meta` 的是旧笔记，见第 6 节。

**不选「给会话表加一列 JSON」的原因**：那样要改三处建表、线上补列、发后端。现在这样小程序单独发版就行，以后想换成一列 JSON，只是换读写的地方。

## 4. 电子法官房间里

- **入口**：房间页导航栏「记录」「身份」旁边加「笔记」，入座的玩家才有，法官没有。面板是页面级的一个组件（和「记录」面板同级），不在视图组件里嵌。
- **笔记和房间一一对应**：第一次点开时建一条笔记，记下房间号；以后进这个房间都是它。不点开就不建，免得每局都多出一条空笔记。
- **自动记**：建了笔记之后，房间页每次拿到新快照就把公开信息并进笔记：座位和昵称、谁出局了、哪天怎么出的、警长是谁、每天的票型和被放逐的人、昨夜死讯。这样对局结束后从「笔记」页再打开，内容还是全的。
- **只用全场都看得到的字段**：快照里的 `players`（座位、昵称、存活）、`sheriffSeatNo`、`rounds`（死讯、放逐票型、警长竞选的上警 / 退水 / 票型 / 当选）、`speech`（当前发言人）。本人的身份、夜间信息、法官才看得到的东西一律不读。加一条测试：把带身份和夜间信息的快照喂进去，笔记里不能出现这些内容。
- **夜里**：可以开，所有人都一样有这个入口。夜里每换一步，笔记面板自动收起（所有人一样），免得有技能的人埋头记笔记错过自己的行动。
- **自动记的内容不能手改**（出局、警长、票型），只有自己的判断能改，避免和房间里的事实对不上。

## 5. 代码怎么放

画面上的判断全放纯函数，页面只管渲染和把点击交给它们（和法官房间同一个做法），每个文件都有单测：

- `utils/notes/model.js`：笔记状态和记录之间的转换（存 / 取）、新旧笔记判断、加一天。
- `utils/notes/board.js`：座位盘的视图（每个号码块的颜色、标记小格、出局变暗）、每天顶上的一行（昨夜谁出局、警长、平安夜）、狼坑汇总、点座位面板的按钮和点击后的新状态。
- `utils/notes/votes.js`：票型分组视图（放逐投票和警长竞选）、两步记票的状态变化、票数（警长 1.5，按投票当时记）、「同一组里都是你标的狼」的提示。
- `utils/notes/speech.js`：发言快捷条有哪些按钮、点了之后记到哪。
- `utils/notes/sync.js`：把房间快照里的公开信息并进笔记。

页面和组件：

- `pages/sessions/index.vue`（笔记列表，改卡片摘要）、`pages/sessions/edit.vue`（新建，基本不动）。
- `pages/sessions/board.vue`：新笔记页（座位盘 + 票型 + 面板 + 记票）。
- `components/NotesBoard.vue`：座位盘和票型的主体，笔记页和法官房间共用（页面直接用一层组件，里面不再嵌组件）。
- `pages/judge/room.vue`：加入口、建笔记、同步快照、夜里换步自动收起。

## 6. 旧笔记

旧笔记（查验 / 投票 / 发言 / 狼坑的时间线）不转换、不删除：列表里照常显示，点开还是原来的详情页，只能看和删，不能再加新记录。新建的都是新版。

## 7. 分两步做

1. **面杀可用**：五个纯函数模块和单测、新笔记页、列表和新建接上。做完面杀就能用。
2. **接进法官房间**：入口、自动记、发言快捷条、夜里自动收起，联调脚本里让机器人开一次笔记，检查没有私密信息进笔记。

每一步都是先写测试再写实现，做完在浏览器里走一遍，再用微信开发者工具的编译器检查一次样式。

## 8. 这次不做

- 对局结束后「对答案」（我猜的和真实身份对比）。
- 把笔记分享到社区。
- 面杀时给座位起名字（只显示几号）。
