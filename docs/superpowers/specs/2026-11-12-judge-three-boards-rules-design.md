# 电子法官：预女猎白、狼王守卫、通灵师机械狼人三个板子的规则对齐

日期：2026-11-12

## 实现中用户改定（2026-11-12，以此为准，下文相应条目作废）

1. **自爆的狼当场出局**，不参与当晚点刀（作废 A1 的「当晚仍参与点刀、天亮才出局」和「本文定的」里相应几条）。最后一只狼自爆当场判好人胜不变。
2. **守卫只挡狼刀，挡不住女巫的毒**（作废 B3）。挡毒 / 弹毒只是学到守卫的机械狼的技能（C5、C6、C7 第 4 步里「被真守卫守 → 不死」作废）。
3. **狼王可以自刀、可以自爆**；被刀、被放逐、被猎人带走都能开枪；只有被毒、被点杀、自爆、是最后一只狼时不能开枪（作废 B2 和拍板第 2 条里「被刀不能开枪」「不能自刀」「不能自爆」）。

## 为什么

`docs/judge/house-rules/` 是用户逐字给定的板子规则，是电子法官的唯一口径。引擎在几处和它对不上，而且通灵师机械狼人板子的两个角色引擎完全不认识，只能开有法官局。用户要先把线上最常开的三个板子做对：

| 线上板子 | 规则文件 | 阵容 |
|---|---|---|
| 2 预女猎白 | `01-预女猎白.md` | 平民 4、预言家、女巫、猎人、白痴、狼人 4 |
| 8 狼王守卫 | `03-狼王守卫.md` | 平民 4、预言家、女巫、猎人、守卫、狼人 3、狼王（线上角色名「黑狼王」） |
| 5 机械狼通灵师 | `08-通灵师机械狼人.md` | 平民 4、通灵师、女巫、猎人、守卫、狼人 3、机械狼 |

做完的标准：这三个板子都能开**无法官**局（支持级别 full），从开局到结算每一步都和规则文件一致；规则文件里写的每一条都有测试钉住。

## 不做的

- 其他板子（混血儿、石像鬼、守墓人、梦魇、魔术师、狼美人、骑士、摄梦人）的机制。
- 旧流程房间（`auto_judge_enabled = 0`，旧版小程序建的）的行为不变。
- 不改胜负规则（屠边）、不改投票 / 上警流程。

## 反目标（技术上能跑也算失败）

- **场外**：任何玩家的手机能从画面、时长、提示里看出别人的身份或夜里做了什么。机械狼那一步、白痴空步、自爆狼参与的狼队那一步，持有者死没死、学没学、带没带刀，所有人看到的步骤时长都一样。
- 自己按记忆补规则。规则文件没写的点在本文里列为「本文定的」，用户可以改。

## 原则：机制跟角色走，不跟板子走

每个角色的机制是固定的，换到哪个板子都一样；板子只决定阵容、夜间顺序和配置。其他规则差异一律落在角色机制上，不加板子开关。

板子配置分两层（都存在 `ruleDetail.judgeRules`，开局时拷进房间）：
- **通用配置项**：每个板子都有，和阵容无关。现在是节奏项：上警默认值、发言时长、警上发言时长、狼队行动时长、单人行动时长。建房时房主还能再调。
- **板子专属配置项**：只有阵容里有对应角色时才出现，决定该角色机制里用户明确说「两种都支持、板子定」的分支。现在是两项：女巫自救（阵容有女巫）、机械狼弹毒（阵容有机械狼）。专属项的默认值写在机制上（女巫默认不能自救、弹毒默认不开），建房请求改不了。

后台板子编辑页按这两层分区显示；`JudgeRules` 补默认值时专属项同样一处强制。

## 用户这次拍板的（写回规则文件）

0. **猎人一律不翻牌**：开枪公告统一「X号发动技能，带走了Y号」，和狼王、学到猎人的机械狼同一句。01 号规则原文「可翻牌带走」标「2026-11-12 用户改定：不翻牌」，README「猎人开枪翻不翻牌」那条改成一律不翻牌。
1. **白痴改机制**（改 01 号规则原文，标「2026-11-12 用户改定」）：白痴被放逐**照样出局**，出局时翻牌，公告写明他是白痴。没有免死，也就没有「翻牌后不能投票」。他是警长时照常走移交 / 撕警徽。被刀、被毒、被枪杀和普通出局一样，不翻牌。
2. **狼王开枪**：被放逐、被猎人开枪带走都能开枪；被刀、被毒不能。是最后一只狼时不能开（那一刻游戏已经结束，好人胜）。
   **猎人开枪**：被刀、被放逐、被狼王或学到猎人的机械狼开枪带走都能开枪；被毒、被点杀不能。所以会有连环开枪，引擎现在就是这样，不改。
3. **最后一只狼自爆**：当场判好人胜，不再进夜晚。这里「狼」指狼人阵营的所有存活者，含狼王、机械狼。

## 要改的行为

### A. 三个板子共用

**A1 自爆的狼当晚仍参与点刀，点刀后死亡**（规则文件各板狼人条）。
- 自爆时：公开公告「X号自爆」（不变），他从那一刻起不再发言、不能投票、不能上警 / 被投，白天剩余流程照旧跳过直接天黑（不变）。他在库里先**标记为已自爆、仍算存活**，不立刻出局。
- 胜负：自爆那一刻按「他已出局」判一次：剩下的存活者里没有狼人阵营 → 好人胜，结束。否则继续。
- 夜里：他照常出现在狼队那一步、能看到队友、能选刀口，他的票和其他狼一样算。
- 天亮结算时他出局（`点刀后死亡`）。他不出现在「昨夜死亡」公告里（全场已经知道他自爆了），不问遗言、不问技能。他死后照常判胜负。
- 双爆吞警徽、竞选推迟的流程不变；只是「出局」的时刻从自爆当场挪到当晚结算。
- 自爆的是警长：自爆当场移交或撕掉警徽（和现在一样），处理完再天黑。
- 昨夜已被刀、死讯还没公布的狼在警上自爆：他算昨夜死亡，不参与今晚点刀，自爆只起推迟竞选 / 警徽流失的作用，仍只算一次出局（和现在一样）。
- 自爆待死的狼夜里和活人一样：能被验（验出狼）、被守、被毒；夜里又被刀或被毒也只死一次。
- 狼王不能自爆（见 B2），机械狼不能自爆（见 C）。所以能自爆的只有机制是 `wolf` 的座位。

**A2 夜间步骤时长**（README「各板通用」）：狼队 60 秒（首夜 90），单人 30 秒，猎人 10 秒，空步 5 秒。引擎现在前三项已对；空步见 B1。持有者出局照叫照等（不变）。

**A3 猎人开枪不翻牌**（拍板第 0 条）：公告保持现在的「X号发动技能，带走了Y号」，猎人、狼王、学到猎人的机械狼同一句。引擎这里不用改，只改规则文件。

### B. 现有机制的修正

**B1 白痴**（01、02）：按上面拍板第 1 条改。机制是全局的，预女猎白混（02）的白痴也一样，02 号规则原文同样标改定。引擎里翻牌免死和「翻牌后不能投票」的逻辑删掉。另加夜里一个 5 秒空步：阵容里有白痴就在夜晚最后叫一声白痴、等 5 秒，什么也不做（规则文件夜间顺序第 5 步）。

**B2 狼王**（03）：
- 开枪：只在**被放逐**或**被猎人开枪带走**时能开；被刀、被毒、被法官点杀、自爆不能。最后一只狼出局时游戏先结束，不开枪（不变）。
- 不能自刀：狼王提交刀口不能选自己（4000「狼王不能自刀」）。普通狼人仍可自刀。
- 不能自爆：`Mechanic.WOLF_KING` 去掉自爆。

**B3 守卫挡毒**（03、08）：守卫守的人当晚被**女巫**的毒，毒不死他。挡不住机械狼的毒和破盾刀。同守同救照死（不变）。

### C. 通灵师机械狼人（08）新机制

两个新机制加进 `Mechanic`：`psychic`（通灵师）和 `mech_wolf`（机械狼）。线上角色 12 机械狼、14 通灵师的 `mechanic` 列用迁移 SQL 填上，后台机制下拉自动出现。加完后板子 5 的支持级别变成 full。

**C1 通灵师**：好人神职，每晚验一人，结果是**具体身份**（对方角色在本板子里的名字，比如「狼人」「女巫」）。验机械狼：没学过显示「机械狼」的角色名；学过显示学到的那个角色名（当晚先学后验，所以当晚学的当晚就显示新身份）。夜间顺序和预言家同一档。

**C2 机械狼：身份与阵营**
- 狼人阵营，算狼（胜负、预言家查验都算狼）。和狼人互不认识：不在狼队那一步、看不到队友，狼人也看不到他。
- 不能自爆。白天和普通玩家一样发言投票。
- 每晚**最先**睁眼，单独一步，30 秒，持有者死了照叫照等。

**C3 学习**
- 整局只学一次，任意一晚都行（含首夜）；没学的晚上这一步问「学不学」，可以不学。
- 学：选一名存活的其他玩家，当场告诉他对方的身份（角色名），学到对方的机制。
- 学到的技能**从下一晚起**生效；例外：学到猎人，学习当晚起出局就能开枪。
- 学到的机制只看对方机制：女巫、守卫、通灵师、猎人、狼人（含狼王：本文定的，学到狼王按狼人算）、平民（含白痴、机械狼以外的其他：本文定的，学到白痴按平民算）。
- 他那一步可以一次提交多件事：没学过又带刀的晚上，可以既学习又刀人；学过的晚上按学到的技能行动，带刀时再加刀口。学狼人的当晚仍只有一刀，两刀从下一晚起。

**C4 带刀**
- 狼人阵营里除他之外的狼（狼人、狼王）全部出局后，他「带刀」。
- 从第二晚起，每晚他那一步先告诉他「你现在带刀 / 没带刀」（只给他本人）。
- 带刀后狼队那一步变成假步骤（照叫照等），刀口在他自己那一步选。
- 刀数：没学过、学到平民或其他非狼技能 → 每晚一刀（普通刀）。学到狼人 → 每晚两刀：一刀普通刀、一刀破盾刀，可以只出一刀，两刀可以打同一人。
- 女巫那一步只告诉女巫**普通刀**的刀口（狼队的刀或他带刀的普通刀）。

**C5 学到的技能**（都在他自己那一步做，时长仍 30 秒）
- **通灵师**：每晚验一人，报具体身份（同 C1）。
- **女巫**：固定一瓶毒，没有解药。他的毒：女巫看不到、救不了；守卫挡不住；被他毒死的猎人 / 学到猎人的人不能开枪。
- **守卫**：每晚守一人，可自守、可空守、不能连守。挡狼刀（普通刀）；挡女巫的毒，按板子配置「弹毒」（C6）。和真守卫守同一人：两个守护都算，人不死。被他守的人当晚又被女巫用解药救：照死（同守同救）。挡不住破盾刀。
- **猎人**：被刀（普通刀）或被放逐出局能开枪，被女巫毒不能。开枪公告同猎人，不翻牌。
- **狼人**：见 C4 两刀。
- **平民**：没有额外技能。

**C6 弹毒**（用户明确要的板子级开关，默认关）：新增 `ruleDetail.judgeRules.poisonBounce`（布尔），开局时和其他规则一起拷进房间。学到守卫的机械狼守的人被女巫毒：
- 关：正常挡毒，被守的人不死。
- 开：被守的人不死，毒反弹给女巫，女巫当晚死，算「被毒杀」（守卫挡不住弹回去的毒）。
- 后台板子编辑页：阵容里有机械狼时出现这个开关（规则文件 README 要求后台可设）。

**C7 一夜的结算顺序**（把上面的规则放到一起；本文定的结算口径，和规则文件逐条一致）：
1. 收集：狼队刀口（多数，平票随机，没人选空刀）或带刀机械狼的普通刀；机械狼破盾刀；真守卫守的人；学守卫的机械狼守的人；女巫救（只能救普通刀口）/ 毒；学女巫的机械狼的毒。
2. 普通刀口 K：被守（真守卫或机械狼守卫任一）且没被解药救 → 活；被解药救且没被守 → 活；既被守又被救 → 死；都没有 → 死。
3. 破盾刀口 B：一律死。B 和 K 是同一人且女巫对他用了解药：解药照常消耗，人照死。
4. 女巫的毒 P：被真守卫守 → 不死；被学守卫的机械狼守 → 弹毒关：不死；弹毒开：不死，女巫死（被毒）。都没守 → 死。
5. 机械狼的毒 M：一律死，守不住。
6. 被毒（P、M、弹回的毒）死的人出局后不能开枪。
7. 自爆的狼当晚出局（A1）。

### D. 前端（小程序）

- 机械狼那一步的操作面板：没学过 → 「学习」（选一人）/ 「不学」，学完显示对方身份。学过 → 第二晚起先显示带没带刀，再按学到的技能出现对应操作（验 / 毒 / 守）。带刀时面板里多一块选刀口（学到狼人时两刀：普通刀、破盾刀，各可不出），和学习 / 技能操作同一步提交。
- 通灵师查验结果显示角色名。
- 自爆后的狼在狼队那一步照常操作；白天他已不在发言 / 投票里。
- 白痴出局公告（只是文案，来自后端事件）。
- 后台：机制下拉多出通灵师、机械狼；板子编辑页阵容有机械狼时显示「弹毒」开关；支持级别徽标随之变化。
