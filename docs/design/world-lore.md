# 夜镇编年史 · 世界观设定

> 全部为 Wolfbook 原创设定，人名、地名、事件都不取自任何商业作品。
> 角色外貌以现有立绘为准，这里只写身世和关系，不和立绘冲突。
> 数据库里的内容由 `deploy/sql/2026-10-28-world-lore.sql` 灌入，之后以后台「世界观」和角色编辑里改的为准。

## 一、世界

### 灰铃镇（人们叫它「夜镇」）

黑松林边上的一座山谷小镇，石板街、尖顶房、一座比全镇都老的钟楼。钟楼里挂着一口银钟，月亮升起时会自己响一声。

三百年来，镇上人都守着一条老规矩：**银钟响过，不出家门。** 钟声之后的街道属于别的东西。久而久之，外乡人管这里叫「夜镇」。

今年秋天，银钟裂了一道缝。从那以后，每到夜里，镇上就有人不见。

### 三方势力

- **守钟人**（好人阵营）：灰铃镇的居民和守护者。大多数人只是面包师、裁缝、酒馆常客，少数人身怀异能：能看星的、会配药的、能走进梦里的。他们的武器是白天的议事厅：每天天亮，全镇聚在钟楼下，投票把可疑的人赶出镇子。
- **月下之族**（狼人阵营）：三百年前就住在黑松林里的狼人家族。他们能变成人形，混在镇民中间过日子。族里分两支：以黑鬃为首、想让人类俯首的「黑鬃氏」，和追随一头白狼、认为狼族该另寻出路的「白霜氏」。
- **局外人**（第三方）：不站在任何一边的存在。他们来夜镇不是为了救谁或吃谁，而是为了自己的故事。

## 二、编年史

| 时间 | 事件 |
| --- | --- |
| 三百年前 | **银钟之约**。第一代镇民在黑松林边开荒，与月下之族的老族长在满月下立约：钟声之前是人的时间，钟声之后是狼的时间，谁也不越界。铸钟的银子里，掺了双方的一滴血。 |
| 一百二十年前 | **尖塔上的守望者**。修钟楼的石匠在塔顶雕了一只滴水嘴兽，用来「替镇子盯着林子」。没人想到它真的在盯。 |
| 三十年前 | **铁匠之夜**。一头年轻的狼越界咬人，铁匠巴纳比赤手空拳把它打回了林子，自己也被咬了一口。镇上从此知道：约定是会被打破的。 |
| 二十年前 | **林边的满月**。猎户布兰的妻子和女儿在林边被狼拖走。他追进黑松林三天三夜，回来时只剩一把枪，从此只用银子弹。 |
| 十年前 | **雾夜**。老守夜人诺曼巡街时走进一场大雾，再没回来。同一夜，酒馆老板夫妇失踪，他们的女儿躲在地窖里活了下来。那一夜所有人的噩梦，长出了一个没有名字的东西。 |
| 今年夏末 | **白狼归来**。被逐出族群十五年的白狼弗罗斯特回到黑松林，带回了一批追随者，狼族内部开始争王位。 |
| 今年秋天 | **银钟裂了**。没人知道是谁做的。当晚，钟声没有响完。第二天，面包房的老贝克没来开门。——游戏从这里开始。 |

## 三、角色

格式：**真名**｜称号｜阵营。下面是身世，最后是人物关系。

### 守钟人 · 神职

**预言家 · 奥菲莉亚·霍恩**｜看星的人｜好人
在星象台长大的孤女，被老天文学家霍恩收养，学会了从星光里读人心。老人临终前把一颗盛着星屑的水晶球交给她，说「银钟裂的那年，去灰铃镇」。她提前三个月就来了，在钟楼下开了一间小小的占星铺，替镇上人看婚事、看收成，也在夜里一个一个地看他们的真面目。
关系：通灵师（同行，彼此不服）、白痴（他总能说中她刚看到的东西）

**女巫 · 薇洛·艾许**｜林中药师｜好人
住在黑松林边缘小屋里的药师，镇上人生病都去找她，病好了却从不请她吃饭。她的药柜最高一格只放两只瓶子：一瓶能把人从鬼门关拉回来，一瓶能把人送进去。母亲留给她的话只有一句：「两瓶都只能用一次，想清楚再打开。」
关系：守卫（他天天来送花，她天天说不要）、猎人（买银粉的老主顾）

**猎人 · 加雷斯·布兰**｜银弹老手｜好人
二十年前的一个满月夜，他的妻子和女儿在林边被狼拖走。他追进黑松林三天三夜，回来时只剩一身伤和一把枪。从那以后他把所有积蓄都换成了银子弹。镇上孩子怕他，因为他从不笑；狼人更怕他，因为他倒下前一定会开最后一枪。
关系：黑狼王（他认定那晚的狼就是它）、驯熊师（一起在山里打过猎的旧识）

**守卫 · 罗兰·维斯特**｜守夜剑｜好人
南方贵族家的三儿子，嫌家里规矩多，十八岁带着一把剑离家游历，替人护镖、赶强盗，一路走到灰铃镇。本来只打算歇一晚，结果在药铺门口多看了一眼，就再也没走。他每晚提着剑在一户人家门口守到天亮，却从不说守的是谁。
关系：女巫（心上人）、骑士（比武输给过他一次，至今不服）

**骑士 · 塞德里克·诺斯**｜誓约骑士｜好人
北境骑士团最年轻的正式骑士，被派来调查灰铃镇的失踪案。他把骑士守则背得一字不差，第一条是「绝不放过恶，绝不错伤善」。所以他白天的决斗只有一次机会：赢了，狼人当场伏诛；输了，他用自己的命谢罪。
关系：守卫（他口中「那个不守规矩的游侠」）、诡术师（追查了三个镇子的骗子）

**白痴 · 汤姆·芬奇**｜钟楼的傻小子｜好人
钟楼看守老芬奇的孙子，十岁那年偷偷爬上钟楼顶，摸了一下银钟，从此说话颠三倒四：大家笑他就哭，大家哭他就笑。镇上开会要把他赶出去的时候，他会掏出爷爷留下的守钟人徽章，大家就只好让他留下。没人知道他那天在钟里看见了什么。
关系：守墓人（爷爷的老朋友，唯一不笑话他的人）、预言家（会突然对她说「你明天会看见狼」）

**通灵师 · 艾琳**｜镜中人｜好人
镇长家客厅里挂了两百年的一面银边古镜，看过太多人说谎，终于在某个夜里从镜框里走了出来。她不会撒谎，也看不得别人撒谎：把镜面朝向一个人，就能照出他真正的身份——不只是好人或狼，是他到底是谁。
关系：预言家（「她只能看到黑白，我能看到名字」）、诡术师（唯一照不清的人，镜子里是一片空白）

**织梦人 · 诺拉·韦伯**｜钟楼织梦人｜好人
十年前在雾夜里失踪的老守夜人诺曼的女儿。她腿脚不便，走不了夜路，就在钟楼顶的阁楼里学会了另一种守夜：纺锤一转，把两个人的梦用银线缝在一起，让他们同生共死、在梦里互通消息。她相信父亲还在某个梦里，只是她还没找到那根线。
关系：摄梦人（同样在梦里找人的朋友）、梦魇之影（她在梦里见过它的影子）

**魔术师 · 马库斯·瓦伦丁**｜午夜魔术师｜好人
巡回马戏团「午夜大篷车」的台柱，来灰铃镇演三场，结果第一场就有观众在后台失踪。他决定留下来，用自己最拿手的把戏对付狼人：每晚悄悄换掉两个人的门牌号，让狼的爪子落空。他嘴上说是为了票房，其实是为了那个失踪的观众。
关系：诡术师（同样在台上讨生活的人，却走了相反的路）、爱神（马戏团里溜进来的小观众）

**摄梦人 · 艾薇·莫斯**｜苦艾酒馆老板娘｜好人
十年前的雾夜，她躲在酒馆地窖里，从地板缝里看着父母被拖进了黑暗。她活了下来，接手了酒馆，也学会了一件别人不会的事：把人带进梦游。被她带走的人那一夜不在床上，狼人扑空；可如果她出了事，梦游的人也醒不过来了。她店里有一杯冒青烟的「苦艾」，喝下去的人会梦见她那晚看见的一切。
关系：梦魇之影（宿敌）、老酒鬼（最老的老主顾）、织梦人（同路人）

**守墓人 · 埃德加·霍洛**｜守墓人｜好人
教堂墓园的守墓人，埋过镇上三代人。狼人死后到了后半夜会现出原形，全镇只有他守在坟边看得见。白天议事厅需要他说真话，晚上镇民却绕着墓园走。他抽一只没点着的烟斗，因为老朋友芬奇说过，火光会把林子里的东西引过来。
关系：白痴（老友的孙子）、黑狼王（他埋过它的两个兄弟）

**驯熊师 · 卡佳·伯恩**｜山路护卫｜好人
北边山里来的商队护卫，身边总跟着一头叫「栗子」的大棕熊。山里人说熊能闻出狼的血味：每天早上，只要她身边坐着狼人，栗子就会冲着天空咆哮一声。她这次是被商队留下来过冬的，结果这个冬天比山里还冷。
关系：猎人（一起打过猎的旧识）、老酒鬼（栗子唯一肯让他摸的人）

### 守钟人 · 镇民

**平民 · 本·贝克 & 梅·索恩**｜提灯的两个孩子｜好人
本是面包房老贝克的学徒，梅是裁缝铺的女儿，两人是隔壁长大的邻居。老贝克失踪后，大人们不敢出门，他俩就一人一盏灯，结伴在钟声前把整条街走一遍。他们没有任何本事，只有眼睛、嘴和手里那一票——这也是全镇大多数人拥有的全部。
关系：彼此（青梅竹马）、狼人（梅说那个新来的绅士身上有股湿毛的味道）、白痴（从小一起疯跑的钟楼小子）

**老酒鬼 · 巴纳比·斯陶特**｜醉铁匠｜好人
三十年前「铁匠之夜」的主角，赤手打退过狼人，也被咬了一口。狼毒留在血里，老神父教他用烈酒压住满月夜的冲动，他就一喝喝了三十年。狼人半夜来咬他，闻到满嘴酒气都要多犹豫一回，所以他总能多扛一次。他说喝酒是为了全镇，酒馆里没人信，也没人拆穿。
关系：摄梦人（看着她长大的老主顾）、黑狼王（三十年前咬他的那头狼，如今成了王）

### 月下之族

**狼人 · 卢西安·格雷**｜灰衣绅士｜狼人
黑鬃氏的年轻成员，今年春天以「外地来的布商」身份住进了镇上的旅店。他礼貌、慷慨，记得每个人的名字，周日还去教堂。只有在满月夜，他会把领结系得特别紧——那是他提醒自己别笑得太早。
关系：黑狼王（族长，他的叔父）、平民（裁缝家的女儿好像在留意他）

**狼美人 · 塞拉菲娜·罗丝**｜玫瑰夫人｜狼人
黑鬃氏的谋士，也是族里最危险的一位。她能化作一个人人都说「非常漂亮」、却没人说得清长相的女人。被她挽住手臂的人会一言不发地跟她走；她倒下的那一刻，那个人也会跟着倒下。她喜欢玫瑰，因为玫瑰也有刺，只是大家总先看到花。
关系：黑狼王（效忠，但各有算盘）、诡术师（她的棋子）

**白狼王 · 弗罗斯特**｜霜鬃｜狼人
满月夜里以雪白的狼形降生，生来就控制不住月圆时的怒火，七岁失手伤了同族，被逐出族群。十五年后他回到黑松林，带着完全掌控的力量和一群追随者，要和黑鬃争王位。他认为狼族不该吃人也不该躲人，而是该有自己的城。为了这个目标，他不在乎先把谁撕碎。
关系：黑狼王（争位的宿敌）、石像鬼（唯一不怕他怒火的存在）

**黑狼王 · 莫德雷德·黑鬃**｜黑鬃之王｜狼人
月下之族的现任族长。三十年前他还是那头越界咬人的年轻狼，被一个铁匠打回了林子，从此认定银钟之约只是人类拴狗的链子。今年秋天银钟裂开，他第一个嗅到了机会：「失去的三百年，由我带大家拿回来。」被逼到绝路时，他会用最后一口气带走一个人。
关系：白狼王（争位）、老酒鬼（三十年前的仇）、猎人（二十年前的血债）

**机械狼 · 伊莱亚斯·科格**｜发条狼｜狼人
钟表匠科格捡来的弃婴，在齿轮堆里长大，成年后第一个满月夜才知道自己身上流着狼血。他不愿做狼，也回不去做人，就给自己打造了一副黄铜发条的身体，谁的本事都能装进去：神职倒下后，他能把对方的能力拆下来，装在自己身上。他说这是在找「属于自己的零件」。
关系：魔术师（他拆过他的道具箱，被当场抓住）、白狼王（白霜氏向他伸过手）

**石像鬼 · 格里姆**｜尖塔守望者｜狼人
一百二十年前石匠雕在钟楼顶的滴水嘴兽，被托付「替镇子盯着林子」。它盯得太久，久到有了心。它想告诉镇民林子里有什么，却只换来石头和咒骂。最后是狼人爬上塔顶，问它看见了什么。从那以后它替狼人盯着镇子：它不和狼群一起行动，却能在夜里看清任何一个人的身份；狼群倒尽之后，它会亲自下塔。
关系：白痴（摸过银钟的孩子，它记得他）、白狼王（相互敬重的孤独者）

**诡术师 · 杰斯特**｜百面戏子｜狼人
巡回剧团里专门替主角挨打的替身演员，演了一辈子别人。剧团被狼群截杀的那晚，他跪着求饶，狼人发现他能变成任何人的样子，就留下了他。从此他替狼人顶身份、换脸、演好人，每到一个镇子都换一个名字，连自己本来叫什么都忘了。
关系：狼美人（她给他新脸，他替她演戏）、骑士（追了他三个镇子）、通灵师（镜子照不出他）

**梦魇之影 · 无名**｜梦底来客｜狼人
它没有名字，因为它是从十年前那场雾夜里所有人的噩梦中长出来的。它住在梦境最深处，每晚第一个醒来，选一个人，用恐惧把他按在床上：那一夜，那个人的本事全都使不出来。它说话很有礼貌，像一位穿着燕尾服的客人，只是从不在镜子里留下影子。
关系：摄梦人（宿敌）、织梦人（它知道她在找谁）

### 局外人

**爱神 · 皮普**｜捣蛋的箭｜第三方
跟着马戏团大篷车溜进镇子的小家伙，背着一张比自己还高的弓。开局第一夜，他会用箭把两个人连成一对：从此他们同生共死。他不在乎谁是狼谁是人，只在乎这个故事够不够精彩。有人说他是神，有人说他只是一个太无聊的孩子。
关系：魔术师（混进马戏团时认识的「大叔」）、守卫（最想射一箭的人）

## 四、在产品里怎么用

- **小程序图鉴页顶部**：一张「夜镇编年史」卡片（钟楼场景图 + 一句话），点进去是世界观页：灰铃镇简介 → 三方势力 → 编年史时间线（每个事件下挂相关角色头像，点头像进角色详情）。
- **角色详情页**：名字卡显示「预言家 · 奥菲莉亚·霍恩」和称号；正文依次是「身世」、技能、FAQ；新增「人物关系」：一排头像 + 一句关系（点头像跳到对方）。去掉主题色色块。
- **后台**：
  - 角色弹窗：「别名」改名为「真名」，新增「称号」和「人物关系」（选角色 + 写一句关系）。
  - 新增「世界观」菜单：编辑小镇简介、三方势力、编年史事件（标题、时间、正文、关联角色、排序）。
- **数据**：真名沿用角色表现有的 `alias` 列；新增 `title`（称号）、`relations`（JSON）两列；世界观存一张新表 `world_lore`（一行 JSON）。上线时用这份文档的内容灌进去，之后在后台改。
- **AI 助手**：知识库里角色条目带上真名和身世，问「预言家叫什么」「夜镇发生过什么」能答上。

## 五、加新角色

- **写法**：照 [`backend/src/main/resources/prompts/role-writing-guide.md`](../../backend/src/main/resources/prompts/role-writing-guide.md) 写（真名、称号、身世、人物关系、编年史五样）。后台「按世界观起草」的 AI 也读这一份，改规范只改那一个文件。
- **完整度**：后台图鉴卡片和角色弹窗会检查，缺了就标「设定不完整」，总览里也会提醒。必需六项：立绘、头像、真名、称号、身世不少于 80 字、人物关系至少 2 条；建议两项（只提示不算缺）：有一条跨阵营的关系、在编年史里出场。保存不拦截，可以先建角色再慢慢补。
- **双向关系**：给 A 写了和 B 的关系、B 还没写回来时，保存后会问要不要去补 B。
- **AI 起草**：新建或编辑角色时填好角色名、阵营、技能，点「按世界观起草」，AI 按规范、世界观和现有角色写一份真名、称号、身世和关系的草稿填进表单，改完再保存。
