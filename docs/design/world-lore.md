## 一、世界

### 月亮在睡

月亮是活的，而且一直在睡。它睡着的时候做梦，梦落到地上，就长成了东西。

很久以前的一个夜里，月亮自己翻了一次身，第一个梦掉进了黑松林。那个梦长出毛和獠牙，学会了用两条腿走路，又学会了白天把毛收起来。这就是**月下之族**：狼人不是诅咒，也不是野兽，是月亮的梦。所以他们只在月光下才现出真形，无月的夜里和人没有分别；所以他们死的时候皮囊是人的，埋进土里后的后半夜才变回狼——梦醒了，就回到梦本来的样子；躺在床上的尸体和人一模一样，谁也看不出来。

月亮有两种翻身。没人管它的时候，它自己翻身，每翻一次就有新的梦落下来；有银器在它耳边响的时候，它会被哄着翻一次身、沉得更深，什么也不漏。人类花了几百年才明白：让月亮一直被哄着睡，比杀光它的梦重要得多。

### 黑松林与七座钟镇

黑松林横在大陆的北边，林子那头是终年落雪的**北境**，林子这头是一片山谷。九百年前，人类沿着林边开荒建村，那是**长夜时代**：没有约定，没有钟，村子一个接一个在夜里空掉。

六百年前，一个看星的人发现了月亮的秘密：星光是月亮睡着时从梦里漏出来的光，在星光下能看见梦本来的形状；而银子是月亮的金属，银器震响的时候，月亮会被哄着沉下去。于是有了第一批**钟匠**。

三百年前，灰铃镇铸了第一口银钟，和狼族立下银钟之约。此后两百年，人们沿黑松林又建了六座镇子，每座仿铸一口钟，合称**七座钟镇**。但只有灰铃镇那口钟掺了血，是真钟；其余六口是仿钟，只能跟着真钟的声音回响。

仿钟一口一口地哑了。有的镇子被狼吃空；有的镇子自己把狼全杀了，可仿钟的回响要有靶子，本地没了狼，回响就落了空，钟再也响不起来，整镇在一个无月的夜里消失。外面的人管那些地方叫**哑镇**。十年前，离灰铃镇最近的雾湾镇哑了。从那以后，整条黑松林只剩灰铃镇一口钟还在响，替整个大陆按着月亮。

### 灰铃镇（人们叫它「夜镇」）

黑松林边上的山谷小镇，石板街、尖顶房、一座比全镇都老的钟楼。钟楼里挂着那口银钟，月亮升起时会自己响一声——不是报时，是哄月亮翻身。

三百年来，镇上人都守着一条老规矩：**银钟响过，不出家门。** 钟声之后的林子属于别的东西，镇子的边界到林边为止。久而久之，外乡人管这里叫「夜镇」。

今年秋天，银钟裂了一道缝。钟匠说不是人做的：六口仿钟都哑了，真钟独自撑了十年，撑不住了。钟一裂，约就松了：狼第一次成群走进了镇子。从那以后，每到夜里，镇上就有人不见。

### 银钟之约的三条

三百年前，第一代镇民和月下之族的老族长在满月下立约。铸钟的银子里掺了双方各一滴血，所以这份约不是人和狼互相立的，是两边一起向月亮立的。钟还在响，约就还在；谁在日光下破约，谁身上的那滴血就会烧起来；夜里越界不烧血，只在约上留下一道裂纹。

约的本意很简单：**狼的时间在林子，人的时间在镇子，谁也不越界。** 三百年里狼只有两次单独越界进镇（铁匠之夜、雾夜），每一次都在约上留下一道裂纹，直到今年秋天钟裂、约松了，狼才成群进了镇子。但约松了不等于约没了：人狼两边仍然被三条约文束缚着——游戏里的每条规则都从这三条里长出来。

**第一条：钟声分昼夜。** 钟声之后是狼的时间，钟声之前是人的时间。狼在夜里可以动手，但誓约蒙住了狼的鼻子：进了镇子的狼闻不出人味，钟声之后人人只认门牌不认脸，狼只能凭门牌找人，所以狼群每晚要先商量、再一起选一户。白天狼必须收起真形；一头狼若在日光下自己现形（自爆），它身上的狼血从那一刻开始烧，烧到后半夜才尽。它用自己的命提前敲了一次钟，那个白天就此结束、全镇直接入夜，它还来得及跟族人走完这最后一夜。

**第二条：日光下的指认。** 誓约给人类的那一半，是白天的议事厅：全镇聚在钟楼下，被多数人指认的那个人，身上的誓约就断了。断了约的人撑不过当夜的钟声，天亮前死在镇边，由守墓人亲手收尸下葬；夜里死在家里的人，则由家里人天亮前匆匆埋掉，不让外人碰。议事厅的钟锤由全镇交给一个人掌着，掌锤的人（警长）指认一个人算一票半；钟锤还没交出去之前要是有两头狼在日光下现形，钟锤就被烧掉，那一局没人再掌锤。这条约文留了两道缝，三百年里先后被两种人发现：摸过银钟的人被指认时钟会替他说话，他不用走，但他那一票从此留在钟里；北境骑士团的人可以把自己的命押上，让一个人的指认当作全镇的指认。

**第三条：一人一份。** 立约那晚，人类手里所有对付梦的本事都被登进了约里：看星人的水晶球、药师的两只瓶子、钟楼看守的徽章、镇长家的镜子，还有后来的人在约文里找到的缝——门槛、门牌、雾。登了记的本事，一样一份，一份同一时间只认一个人，所以每种神职全镇只有一个；一夜只动一次（女巫一晚一瓶、守卫一晚一人）；门槛和解药这一对本事落在同一个人身上会相撞，把人撕了（同守同救照死）。狼血那一滴也一样流进了狼族几支血脉：月下之族的王族、玫瑰夫人，都是那滴狼血长出来的东西。

### 三方势力

- **守钟人**（好人阵营）：灰铃镇的居民和守护者。大多数人只是面包师、裁缝、酒馆常客，少数人掌着登进约里的本事：能看星的、会配药的、能走进梦里的。他们的武器是白天的议事厅，他们的职责是让钟一直响下去。
- **月下之族**（狼人阵营）：月亮的梦，三百年前就住在黑松林里的狼人家族。始祖留下两支血脉：以黑鬃为首、认为狼该让人俯首的**黑鬃氏**，和追随白狼、认为狼该离开人和林子、有自己的城的**白霜氏**。今年两支正在争王位，但在镇子里，他们先是狼。
- **局外人**（第三方）：既不守钟、也不属月的东西，来自七座钟镇之外。他们来夜镇不是为了救谁或吃谁，而是为了自己的故事。（目前没有角色，留给以后。）

## 三、角色

格式：**真名**｜称号｜阵营。下面是身世，最后是人物关系。

### 守钟人 · 神职

**预言家 · 奥菲莉亚·霍恩**｜看星的人｜好人
六百年前第一个看星的人留下了一颗盛着星屑的水晶球，看星的本事就在这颗球里，一代传一代；三百年前立约那晚，它是第一件被登进约里的东西。球传到老天文学家霍恩手上，霍恩在星象台收养了一个孤女，教她从星光里读人心：星光是月亮梦里漏出来的光，在星光下，梦长出来的东西藏不住形状。老人临终前把水晶球交给她，说「银钟裂的那年，去灰铃镇」。她提前三个月就来了，在钟楼下开了一间小小的占星铺，替镇上人看婚事、看收成，也在夜里一个一个地看他们的真面目。她只看得见黑白：是人，还是梦。
关系：通灵师（同行，彼此不服：「她只能看到黑白，我能看到名字」）、白痴（他总能说中她刚看到的东西）、梦魇之影（星光照不出它的脸，只照得见一张白面具）

**女巫 · 薇洛·艾许**｜林中药师｜好人
三百年前铸钟剩下的那罐银屑交给了林边的药师艾许家，艾许家用它配出了两瓶药：一瓶掺人血那一滴的影子，能把人从鬼门关拉回来；一瓶掺狼血那一滴的影子，能把人送进去。两瓶药传了十几代，谁当药师谁接着配，每一代各只能配出一瓶。薇洛住在黑松林边缘的小屋里，镇上人生病都去找她，病好了却从不请她吃饭。她的药柜最高一格只放那两只瓶子，母亲留给她的话只有一句：「两瓶都只能用一次，一夜只能开一瓶，自己喝不得。」她还替猎人磨银粉，替酒馆配苦艾。
关系：守卫（他天天来送花，她天天说不要）、猎人（买银粉的老主顾）、摄梦人（她替酒馆配那杯苦艾）、机械狼（有一晚扒着她药铺的窗，盯着那两只瓶子看了很久）

**猎人 · 加雷斯·布兰**｜银弹老手｜好人
二十年前的一个满月夜，他的妻子和女儿在林边被狼拖走。他追进黑松林三天三夜，打死了两头狼，回来时只剩一身伤和一把枪，指了路让守墓人去抬尸体。那两头狼是黑鬃族长的兄弟，他从此认定拖走妻女的就是黑鬃。他把所有积蓄都换成了银子弹，银粉是从药师那里买的——银子是月亮的金属，打进梦里，梦就散。镇上孩子怕他，因为他从不笑；狼人更怕他，因为他倒下前一定会开最后一枪。女巫那瓶掺着狼血影子的毒，会先压住他扣扳机的那只手。
关系：黑狼王（他认定那晚的狼就是它）、女巫（卖给他银粉的药师）、骑士（骑士团想收编他的银子弹，他把人赶出了门）

**守卫 · 罗兰·维斯特**｜守夜剑｜好人
南方贵族家的三儿子，嫌家里规矩多，十八岁带着一把剑离家游历，替人护镖、赶强盗，一路走到灰铃镇。今年春天他本来只打算歇一晚，结果在药铺门口多看了一眼，就再也没走。他在约文里找到了一道缝：钟声之后才是狼的时间，可只要有人提着剑横在一户人家的门槛上，钟声就进不了那道门，这一户的夜就还没开始，刀和毒都落不进去。门槛上的缝一夜只能借一次，同一户不能连守两晚；若那一夜药师的解药也落在同一个人身上，门槛和解药相撞，人反而活不成。魅惑是梦，不走门，门槛拦不住。他每晚守到天亮，却从不说守的是谁。
关系：女巫（心上人）、骑士（比武输给过他一次，至今不服）、魔术师（有一晚守错了门，第二天才知道是他换的门牌）、狼人（旅店里同住的「布商」，总笑着问他晚上守的是哪一户）

**骑士 · 塞德里克·诺斯**｜誓约骑士｜好人
北境骑士团是七座钟镇之外唯一还记得银钟之约的人。六座哑镇都是他们去收的尸，所以骑士团立了一条守则，第一条是「绝不放过恶，绝不错伤善」。他们在约文第二条里找到了一道缝：把自己的命押上，一个人的指认就能当作全镇的指认。塞德里克是团里最年轻的正式骑士，灰铃镇银钟裂开那个月，他被派来调查失踪案。他白天的决斗整局只有一次：赢了，狼人当场伏诛，那一天的议事就此结束、全镇直接入夜；输了，他用自己的命谢罪。
关系：守卫（他口中「那个不守规矩的游侠」）、狼美人（他在旅店舞厅里对她拔过一次剑，被全镇笑了一天）、猎人（他想收编那些银子弹，被赶了出来）、白狼王（骑士团收哑镇尸首的记录里，有一头在废墟间游走的白狼）

**白痴 · 汤姆·芬奇**｜钟楼的傻小子｜好人
钟楼看守芬奇家守了三百年的钟，守钟人徽章就是铸钟剩下的银子打的。汤姆十岁那年偷偷爬上钟楼顶，摸了一下银钟，钟认下了他：从此他说话颠三倒四，大家笑他就哭，大家哭他就笑，时不时说中一句还没发生的事。镇上开会要把他赶出去的时候，他会掏出爷爷留下的徽章，钟会替他响一声，大家就只好让他留下。但他那一票从此留在钟里，再也投不出去。没人知道他那天在钟里看见了什么，塔顶的石像知道。
关系：守墓人（爷爷的老朋友，唯一不笑话他的人）、预言家（会突然对她说「你明天会看见狼」）、石像鬼（他摸钟那天，它在塔顶看着）、平民（从小一起疯跑的伙伴）

**通灵师 · 艾琳**｜镜中人｜好人
三百年前铸钟剩下的银子，第一份打成了一面椭圆的银边镜子，挂进镇长家的客厅。镜子里的银和钟里的银是同一炉，钟认得谁，镜子就照得出谁。它挂了三百年，看过太多人在镜子前说谎。今年秋天钟裂开的那一刻，镜面也裂了一道缝，她从缝里走了出来。她不会撒谎，也看不得别人撒谎：把镜面朝向一个人，就能照出他真正的身份——不只是好人或狼，是他到底是谁。
关系：预言家（「她只能看到黑白，我能看到名字」）、梦魇之影（镜子里照出来的是一张空椅子）、机械狼（镜子只照得出他身上新装的那块零件，照不出零件下面的他）

**魔术师 · 马库斯·瓦伦丁**｜午夜魔术师｜好人
巡回马戏团「午夜大篷车」在七座钟镇之间跑了几十年，钟镇一座一座哑掉，它的路线一年比一年短。马库斯是台柱，今年秋天来灰铃镇演三场，结果第一场就有观众在后台失踪。他决定留下来，用自己最拿手的把戏对付狼人：钟声之后人人只认门牌不认脸，狼靠门牌找人，星光和药也都落在门牌上，他就每晚悄悄换掉两户人家的门牌号——那一夜落在这两户上的一切都会调换，天亮门牌复原。门牌是三百年的老东西，一生只肯被换一次。他嘴上说是为了票房，其实是为了那个失踪的观众。
关系：机械狼（拆过他道具箱、被当场抓住的小偷）、黑狼王（他后来知道，带走那个观众的就是黑鬃）、守卫（害他守错过一晚门）

**摄梦人 · 艾薇·莫斯**｜苦艾酒馆老板娘｜好人
十年前的雾夜，她躲在酒馆地窖里，从地板缝里看着父母被拖进了黑暗。雾是从哑掉的雾湾镇翻过来的，带着月亮的梦；她在雾里躲了一整夜，醒来时学会了一件别人不会的事：把人带进梦游。被她带走的人那一夜不在床上，在月亮的梦里，狼人扑空，药师的药也落不到他身上；可如果她在夜里出了事，或者把同一个人连带两晚、走得太深，梦游的人就再也醒不过来。她活了下来，接手了酒馆，店里有一杯药师替她配的、冒青烟的「苦艾」，喝下去的人会梦见她那晚看见的一切。
关系：梦魇之影（宿敌，同一场雾夜里长出来的两样东西）、黑狼王（她记得地窖缝外那双眼睛）、女巫（替她配苦艾的人）

**守墓人 · 埃德加·霍洛**｜守墓人｜好人
教堂墓园的守墓人，埋过镇上三代人。二十年前猎人从林子里回来指了路，他带人把两具人模人样的尸体抬回墓园，埋在最深处，入土后的后半夜亲眼看着它们变回狼——梦醒了，就回到梦本来的样子。从那以后他知道：死人的皮囊是人的，埋进土里后的后半夜才露出真形。被全镇指认、天亮前死在镇边的人由他亲手下葬，坟边只有他；夜里死在家里的人由家里人匆匆埋掉，他碰不到，也就看不见。白天议事厅需要他说真话，晚上镇民却绕着墓园走。他抽一只没点着的烟斗，因为老朋友芬奇说过，火光会把林子里的东西引过来。
关系：白痴（老友的孙子）、黑狼王（他埋过它的两个兄弟）、石像鬼（他夜里在坟边，它夜里在塔顶，全镇只有他们两个整夜睁着眼）

### 守钟人 · 镇民

**平民 · 本·贝克 & 梅·索恩**｜提灯的两个孩子｜好人
本是面包房老贝克的学徒，梅是裁缝铺的女儿，两人是隔壁长大的邻居。老贝克失踪后，大人们不敢出门，他俩就一人一盏灯，结伴在钟声前把整条街走一遍。他们没有任何本事，只有眼睛、嘴和手里那一票——这也是全镇大多数人拥有的全部，也是誓约第二条真正的力量：狼怕的从来不是神职，是全镇一起指认的那一票。
关系：彼此（青梅竹马）、狼人（梅说那个新来的绅士身上有股湿毛的味道）、白痴（从小一起疯跑的钟楼小子）

### 月下之族

**狼人 · 卢西安·格雷**｜灰衣绅士｜狼人
黑鬃氏的年轻成员，族长的侄子，今年春天以「外地来的布商」身份住进了镇上的旅店。他礼貌、慷慨，记得每个人的名字，周日还去教堂。誓约蒙住了他的鼻子，所以他白天用眼睛记门牌、记谁住在哪一户，夜里和族人商量好了才动手。只有在满月夜，他会把领结系得特别紧——那是他提醒自己别笑得太早，也别在日光下露出真形：一头狼在白天自己现形，狼血从那一刻烧到后半夜，换来的只是让全镇提前入夜一次、自己跟着族人走完最后一夜。
关系：黑狼王（族长，他的叔父）、平民（裁缝家的女儿好像在留意他）、狼美人（「布商」这个身份是她替他安排的）、守卫（旅店里同住的游侠，他一直想知道那把剑每晚守在谁家门口）

**狼美人 · 塞拉菲娜·罗丝**｜玫瑰夫人｜狼人
黑鬃氏的谋士，也是族里最危险的一位。狼血那一滴在她身上长成了另一种东西：她本身就是一个梦，没有狼血可烧，所以她不能在日光下现形，也不会对自己下刀。她能化作一个人人都说「非常漂亮」、却没人说得清长相的女人。狼群商量完刀口后，她会单独去找一个人，被她挽住手臂的人就走进了她的梦里，一言不发地跟她走；她倒下的那一刻梦就散了，那个人也会跟着倒下，连猎人都来不及开枪。她喜欢玫瑰，因为玫瑰也有刺，只是大家总先看到花。
关系：黑狼王（效忠，但各有算盘）、骑士（那个在舞厅里对她拔剑的愣头青）、狼人（她替他安排了「布商」的身份）

**白狼王 · 弗罗斯特**｜霜鬃｜狼人
始祖白霜那一支的直系，满月夜里以雪白的狼形降生，生来就控制不住月圆时的怒火，七岁失手伤了同族，被逐出黑松林。他一路向北，这十五年里走遍了六座哑镇：有的被狼吃空，有的把狼杀光后在无月之夜整镇消失。他在废墟里学会了掌控自己，也看明白了一件事：狼吃人和狼躲人都是死路，狼该有自己的城。今年夏末他带着追随者回来和黑鬃争王位，为了这个目标，他不在乎先把谁撕碎。王族的血里留着月亮的一次翻身，白霜这一支是次子的血，只连着自己，烧起来谁也不疼；白霜氏信的就是「不躲」：他可以在日光下自己现形，把那一次翻身当场烧掉、带走一个人。
关系：黑狼王（争位的宿敌）、石像鬼（唯一不怕他怒火的存在，同样在塔顶和废墟里看过太多）、机械狼（白霜氏向他伸过手：「你也在找自己的城」）、骑士（在哑镇废墟里远远见过收尸的骑士团，彼此没有动手）

**黑狼王 · 莫德雷德·黑鬃**｜黑鬃之王｜狼人
始祖黑鬃那一支的直系，月下之族的现任族长。三十年前他还是那头越界咬人的年轻狼，被一个铁匠打回了林子；二十年前他刚接过族长的位子，两个兄弟就死在猎人枪下。他从此认定银钟之约只是人类拴狗的链子。今年秋天银钟裂开，他第一个嗅到了机会：「失去的三百年，由我带大家拿回来。」王族的血里留着月亮的一次翻身：被全镇指认赶出镇子时它一定会动，他会用它带走一个人。黑鬃这一支是始祖长子的血，连着全族，烧起来整族都疼，所以他不能在日光下自己现形，族里不许；他也不会对自己下刀。女巫那瓶掺着狼血影子的毒会先把这一次翻身用掉，被毒倒的他什么也带不走。
关系：白狼王（争位）、猎人（二十年前的血债）、守墓人（他埋过它的两个兄弟）、狼人（侄子）、狼美人（族里的谋士，各有算盘）、摄梦人（雾夜那晚拖走酒馆夫妇的狼里有他）、魔术师（马戏团后台那个失踪的观众是他带走的）

**机械狼 · 伊莱亚斯·科格**｜发条狼｜狼人
三百年前铸第一口银钟的钟匠姓科格，这一家守了三百年的钟楼机芯。钟表匠科格捡来一个弃婴，在齿轮堆里把他养大，今年春天，成年后第一个满月夜，他才知道自己身上流着狼血。他不愿做狼，也回不去做人，就用钟楼里换下来的旧零件给自己打造了一副黄铜发条的身体。约里登记的本事认人，他的铜身体认零件：他只要在夜里仔细看一个人一次，就能把那人身上那份本事的样子拓下来、铸成零件装进自己身上，从第二晚起照着用，整局只能拓一次。药师的两只瓶子是一对，铜只拓得下毒的那一只，没有解药；铜不认门槛上的约（他的毒，守门的剑挡不住）；他的狼血裹在铜壳里，日光烧不到，所以他不能在日光下现形。他和狼群互不相识，从不一起行动；狼群倒尽之后，他才会自己拿刀。他说自己是在找「属于自己的零件」——零件要在月亮的梦里才转得动，所以他需要狼赢。
关系：魔术师（他拆过他的道具箱，被当场抓住）、白狼王（白霜氏向他伸过手）、通灵师（镜子只照得出他身上新装的那块零件）、女巫（他扒着药铺的窗看过那两只瓶子）

**石像鬼 · 格里姆**｜尖塔守望者｜狼人
一百二十年前石匠雕在钟楼顶的滴水嘴兽，被托付「替镇子盯着林子」。石头不是人也不是狼，不在誓约里，所以它不用闭眼，一百二十年里整夜整夜地看，看清了镇上每一户门后到底住着什么。它盯得太久，久到有了心。它想告诉镇民林子里有什么，却只换来石头和咒骂；最后是狼人爬上塔顶，问它看见了什么，临走让它舔了一滴狼血——那滴血把它登进了约里：从那以后它在星光下现的是梦的形状，看星的人、守坟的人都把它算作狼，被指认也一样断约。它替狼人盯着镇子，却不认识他们、不和狼群一起行动，只在夜里看清一个人的身份；狼群倒尽之后，它会亲自下塔。钟裂之后，它白天能化作一个石匠模样的旅人坐进议事厅。十二年前有个孩子爬上塔顶摸了钟，它记得他。
关系：白痴（摸过银钟的孩子，它记得他）、白狼王（相互敬重的孤独者）、守墓人（全镇只有他们两个整夜睁着眼）

**梦魇之影 · 无名**｜梦底来客｜狼人
它没有名字，因为它不是从狼族生出来的，是从月亮梦里漏出来的。十年前的雾夜，雾湾镇的仿钟哑了，真钟独自撑着月亮，月亮自己翻了一次身，漏出了一个梦，落进那一夜全镇人的噩梦里，长成了它；它身上那件燕尾服，是走进雾里的守夜人诺曼的。它住在梦境最深处，每晚第一个醒来，先独自选一个人，用恐惧把他按进更深的梦里，再去狼群里坐下。被按住的人自己醒着，身上的本事却要睡到下一次钟声才醒：那一夜使不出来，第二天白天被指认，他也开不了枪；看星的看不见，配药的开不了瓶，守门的守不住，狼群里有一头被按住了，整群狼当晚都动不了。同一个人第二夜再按会被按死，死在梦底的人会把它一起拖回梦底，所以它按不了连着的两夜。它说话很有礼貌，像一位穿着燕尾服的客人，只是镜子里照出来的永远是一张空椅子。
关系：摄梦人（宿敌，同一场雾夜里长出来的两样东西）、通灵师（她的镜子里它是一张空椅子）、预言家（星光照不出它的脸）

## 四、规则对照表

每条游戏规则在世界里的原因。规则本身以 `docs/judge/house-rules/` 为准。

| 规则 | 原因 |
| --- | --- |
| 狼人只在夜里动手 | 誓约第一条：钟声之后是狼的时间。 |
| 狼群每晚统一刀口 | 誓约蒙住了狼的鼻子，狼只能凭门牌找人，要先商量。 |
| 出局不翻牌；守墓人只能验被放逐者 | 死人的皮囊是人的，入土后的后半夜才现原形；放逐者由守墓人亲手下葬，夜里死的人家里人自己埋，他碰不到。 |
| 全镇投票放逐 | 誓约第二条：被多数人指认，身上的约就断了，撑不过当夜钟声。 |
| 警长 1.5 票；双爆警徽流失 | 议事厅的钟锤交给一个人掌着；钟锤交出去之前有两头狼在日光下现形，钟锤被烧掉。 |
| 白痴被投出不死、失去投票 | 钟认下了摸过它的人，替他说话；他那一票留在钟里。 |
| 骑士决斗一次、决斗狼直接入夜 | 骑士团押上命，让一个人的指认顶全镇；指认成立等于那一天的议事结束。 |
| 狼人白天自爆、直接入夜、当晚仍参与点刀 | 狼在日光下自己现形等于提前敲了一次钟；狼血从现形那刻烧到后半夜才尽。 |
| 每种神职全镇只有一个 | 誓约第三条：登进约里的本事一份只认一个人。 |
| 女巫一晚一瓶、不能自救 | 本事一夜只动一次；药里掺的是誓约的影子，持瓶的人自己喝不得。 |
| 守卫刀毒都挡、不能连守、可自守 | 剑横在门槛上钟声进不来，这一户的夜没开始；门槛上的缝一夜只能借一次。 |
| 同守同救照死 | 门槛和解药这一对落在同一个人身上相撞。 |
| 猎人被刀、被放逐能开枪，被毒不能 | 毒药掺的是狼血影子，先压住他扣扳机的手。 |
| 黑狼王被放逐能开枪、被毒不能、不能自爆、不能自刀 | 王血里那一次翻身在指认时一定会动；毒先把这次翻身用掉；黑鬃的王血连着全族，在日光下烧会整族都疼，族里不许。 |
| 白狼王能自爆带人 | 白霜的王血只连着自己，烧起来不伤族人；白霜氏信的就是「不躲」。 |
| 狼美人魅惑、死时殉情、不能自爆、不能自刀 | 她本身是梦，没有狼血可烧；被挽住的人进了她的梦，梦散了人也醒不过来。 |

## 五、在产品里怎么用

- **小程序图鉴页顶部**：一张「夜镇编年史」卡片（钟楼场景图 + 一句话），点进去是世界观页：灰铃镇简介 → 三方势力 → 编年史时间线（每个事件下挂相关角色头像，点头像进角色详情）。「一、世界」里「月亮在睡」「银钟之约的三条」这两段可以作为小镇简介的扩展段落。
- **角色详情页**：名字卡显示「预言家 · 奥菲莉亚·霍恩」和称号；正文依次是「身世」、技能、FAQ；「人物关系」：一排头像 + 一句关系（点头像跳到对方）。
- **后台**：
  - 角色弹窗：「真名」、「称号」和「人物关系」（选角色 + 写一句关系）。
  - 「世界观」菜单：编辑小镇简介、三方势力、编年史事件（标题、时间、正文、关联角色、排序）。
- **数据**：真名沿用角色表的 `alias` 列；`title`（称号）、`relations`（JSON）两列；世界观存 `world_lore` 表（一行 JSON）。这份文档改了之后要重新同步进库。
- **AI 助手**：知识库里角色条目带上真名和身世；「四、规则对照表」可以一起喂给助手，问「女巫为什么不能自救」能按世界观答。

## 六、加新角色

- **写法**：照 [`backend/src/main/resources/prompts/role-writing-guide.md`](../../backend/src/main/resources/prompts/role-writing-guide.md) 写（真名、称号、身世、人物关系、编年史五样）。后台「按世界观起草」的 AI 也读这一份，改规范只改那一个文件。
- **挂在哪**：新角色的本事要么是立约时登进约里的一份、或后来在约文里找到的一道缝（好人），要么是狼血那一滴长出来的东西（狼人），要么来自七座钟镇之外（局外人）；在「四、规则对照表」里补一行它的规则为什么是这样。
- **完整度**：后台图鉴卡片和角色弹窗会检查，缺了就标「设定不完整」，总览里也会提醒。必需六项：立绘、头像、真名、称号、身世不少于 80 字、人物关系至少 2 条；建议两项（只提示不算缺）：有一条跨阵营的关系、在编年史里出场。保存不拦截，可以先建角色再慢慢补。
- **双向关系**：给 A 写了和 B 的关系、B 还没写回来时，保存后会问要不要去补 B。
- **AI 起草**：新建或编辑角色时填好角色名、阵营、技能，点「按世界观起草」，AI 按规范、世界观和现有角色写一份真名、称号、身世和关系的草稿填进表单，改完再保存。
