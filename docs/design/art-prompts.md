# Wolfbook 出图提示词

风格：**美式 2D 动画角色设计 × 中世纪哥特奇幻小镇 × 桌游 / 跑团夜场**，平涂漫画感，带暗黑哥特的叙事氛围。

**每个条目只有一段提示词，整段复制粘贴就能生成**：风格、构图、阵营、人物属性、外观、背景、光效和"不要出现"的内容都已经写在同一段里。

## 好人和坏人怎么区分

每段角色提示词里都有一句「阵营」说明，告诉模型这个角色要让人一眼看出是好人、坏人还是第三方。具体长什么样由模型在这个约定内发挥，不单独禁止某个特征：

- **好人阵营**：表情开放友善，双眼睁开、眼神清澈坦诚、看向观众，正面柔和暖光，阴影轻，姿态放松或保护性。可以神秘、俏皮、悲伤，但底色是善意。
- **狼人阵营**：眼神带攻击性或算计，狞笑 / 冷笑 / 得意的笑，冷光从下方或侧后方打，阴影重、对比强，姿态前倾或居高临下。可以优雅帅气、可以有悲剧色彩，但一定危险。
- **第三方**：善恶难辨、带着玩味，狡黠但不凶恶，明亮且带戏剧化高光。

## 角色的背景故事从哪来

每段「人物属性」= 游戏里的职责 + 一小段背景故事 + 性格。背景故事参考了两处公开资料，再改写成我们这个小镇的设定（**不用对方的人名和原文**，只借故事骨架）：

- 网易《狼人杀》官方角色故事（萌娘百科整理）：预言家是被老占卜师收养的流浪孤儿；女巫继承祖母的位子、被镇民敬而远之；猎人月圆夜失去妻女、用银子弹复仇；守卫是出身贵族的游侠、对女巫一见钟情；魔术师是十七岁自学成才的富家天才；摄梦人是父母被狼人带走的酒馆老板娘；狼王是要重振家族荣耀的族长；白狼王是月圆夜失控伤过同族的雪白异类；狼美人用美貌和歌声般的嗓音把人带走；石像鬼是教堂顶上活过来、被人类驱赶的滴水嘴兽；梦魇之影是幻梦境里被诅咒唤醒的怪物；熊灵是森林之母的长子、旅人的「咆哮护卫」。
- 三个没有同名官方角色的，按你定的对标改写：**白痴 ← 愚者**（长老的孙子，偷看大卷轴后神志不清、大智若愚，风车和卷轴）；**通灵师 ← 魔镜少女**（洞察万物的古镜化成的少女，主人死后带着碎镜来找狼）；**机械狼 ← 觉醒隐狼**（狼人后代，成年前连预言家都看不穿，不认人也不认狼，给自己造了一具黄铜躯壳）。
- 法国原版《Les Loups-garous de Thiercelieux》的村庄设定：表面平静的小村庄，每到夜里有人变成狼人吞食邻居，天亮后村民集会找出藏在身边的狼；丘比特、守卫（Salvateur）、村中白痴、驯熊师、生锈之剑骑士等角色都源于此。

没有对标的角色（织梦人、老酒鬼、诡术师、守墓人、平民），我按游戏职责和小镇设定自己写了故事：织梦人是走不了夜路的守夜人女儿；老酒鬼是被咬过一口、靠烈酒压住狼毒的老铁匠；诡术师是剧团被屠后替狼人演戏的替身演员；守墓人是唯一看得见狼人死后现形的人。

## 出图顺序

1. 先只出 **1. 预言家**（新版：睁眼、正面），确认画风。
2. 满意后把它当参考图 / 垫图，出第一批剩下的 5 个角色（平民是男女同图的一张）和前两张场景。
3. 再出其余角色、场景和板子主视觉。

工具支持的话，固定同一个随机种子（seed），画风会更统一。
