# 白狼王骑士

> 白天的板：白狼王能自爆带人，骑士能翻牌决斗。狼人要算好什么时候炸，好人要算好什么时候决斗，一局常常在白天就翻盘。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |
| 好人阵营 | 预言家、女巫、守卫、骑士（神职 4）+ 平民 × 4 |
| 狼人阵营 | 狼人 × 3 + 白狼王 |
| 胜利条件 | 屠边 |
| 支持级别 | partial 🔧（白狼王、骑士两个机制待实现） |
| 数据库 id | 4 |

## 2. 角色与技能

预言家、女巫、平民、狼人同 02；守卫同 03。

### 白狼王 🔧 `white_wolf_king`
- 夜里和狼队一起刀人，普通狼队成员。
- 白天**发言阶段**可以自爆，自爆时可以带走一名存活玩家（也可以不带）。自爆后直接入夜，自爆者和被带走者都没有遗言。
- 被放逐、被猎人 / 狼王带走、被毒、被刀出局时**没有任何技能**（只有自爆能带人）。
- 可以在警长竞选阶段（警上发言时）自爆带人；警徽按「双爆吞警徽」处理（见 README 2.4）。
- 被预言家查验为狼人。
- ⚠️ 变体：有的桌规定白狼王自爆只能带「当前在场发言过的玩家」，本项目不限制，任何存活玩家都能带。

### 骑士 🔧 `knight`
- 白天**发言阶段**（轮到自己或别人发言时都可以）翻牌，指定一名存活玩家决斗：
  - 对方是狼人阵营 → 对方立即出局，**当天直接入夜**，不投票；被决斗出局的狼没有遗言。
  - 对方是好人阵营 → 骑士自己立即出局，白天**继续**（发言照常、照常投票）；骑士没有遗言。
- 整局只能决斗一次（翻牌就用掉了）。
- 决斗不能指向自己。
- ⚠️ 警长竞选阶段能不能决斗：本项目**不能**（警上只能发言和自爆）；变体：有的桌允许。
- ⚠️ 骑士决斗出狼王 / 白狼王：对方出局，狼王是否能开枪带人？本项目：**狼王可以**（不是被毒死），白狼王**不能**（它只有自爆技能）。
- 骑士决斗成功时如果对方是警长：警徽照常移交，然后入夜。
- 骑士夜里被刀、被毒照常死，无特殊。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 守卫请睁眼，今晚你要守护谁？ | 守 |
| 2 | 守卫请闭眼。狼人请睁眼（白狼王一起），请统一意见刀人 | 狼队含白狼王选刀口 |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 救 / 毒 |
| 4 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 查 |
| 5 | 预言家请闭眼。天亮了 | |

骑士和白狼王的技能都在白天，夜里没有专属步骤。

## 4. 白天流程

在 README 的基础上，发言阶段多两种打断：

**白狼王自爆**：任何一名发言者发言时，白狼王可以举手宣布自爆并指定带走的人 → 法官确认两人出局 → 直接入夜（当天不投票、无遗言；警长竞选阶段按「双爆吞警徽」处理）。

**骑士决斗**：骑士宣布翻牌决斗 X 号 → 法官查看 X 的身份牌 →
- X 是狼：宣布「决斗成功，X 号出局」，处理 X 的出局技能（狼王带人）和警徽移交，直接入夜；
- X 是好人：宣布「决斗失败，骑士出局」，处理骑士的警徽移交（如果是警长），白天从被打断处继续。

决斗结果只公布胜负，不公布 X 的具体身份（狼王还是普通狼）。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 白狼王自爆带走 A | 白狼王、A 出局，无遗言，入夜 |
| 白狼王自爆带走猎人（本板无猎人，供同类板参考） | 猎人可以开枪 |
| 白狼王被放逐 | 出局，不能带人，有遗言 |
| 白狼王被毒 | 出局，无技能 |
| 骑士决斗狼人 | 狼出局，入夜 |
| 骑士决斗白狼王 | 白狼王出局（无技能），入夜 |
| 骑士决斗好人 | 骑士出局，白天继续 |
| 骑士决斗警长（好人） | 骑士出局，警长无事 |
| 骑士是警长，决斗失败 | 先移交警徽再出局 |
| 白狼王自爆时骑士想决斗 | 自爆先宣布的先生效；法官以先举手为准 |
| 最后一只狼是白狼王，自爆带走最后一个神 | 同一次出局双方同时达成 → 狼人胜 |

## 6. 特殊判定

- ⚠️ **骑士决斗成功直接入夜，当天警长竞选还没完成**：原稿写「竞选终止，本局无警长（与自爆同样处理）」，但自爆已改成双爆吞警徽（README 2.4），做骑士时再定决斗是不是也按竞选推迟处理。
- **骑士决斗失败后当天还能投票吗**：能，骑士只是出局，流程不变。
- **白狼王第一天警上自爆带走真预言家**：合法且常见；电子法官要允许在 `sheriff_speech` 阶段自爆。
- **白狼王自爆能不能带自己人**：可以（引擎不限制）。
- **女巫毒白狼王**：白狼王出局，无技能，没有遗言（夜间出局）。

## 7. 电子法官实现要点

- 新增机制 `white_wolf_king`：`NightKind.WOLF`、狼队、优先级 2；白天动作 `self_destruct`（带 `targetSeatNo` 可选）。自爆只在 `sheriff_speech` / `day_speech` 阶段允许，`exile_vote` 等阶段 4002。自爆带走者的出局标记为「被白狼王带走」：无遗言、可触发对方的出局技能（猎人 / 狼王），然后直接切 `night_action`。
- 新增机制 `knight`：无夜间步骤；白天动作 `duel`（`targetSeatNo`），只在 `day_speech` 阶段允许（`sheriff_*` 阶段 4002，可配置放开）。结算：目标 `faction = 狼人` → 目标出局（走正常出局待办，狼王可开枪）→ 切 `night_action`；否则骑士出局（走待办：警徽移交）→ 白天继续。每局一次，用过后 `status_json.knightUsed = true`。
- 公告：「X 号骑士翻牌决斗 Y 号，决斗成功，Y 号出局」/「决斗失败，X 号出局」，不写 Y 的具体角色。
- 两个动作都要进 `judge_action_events`（public），对局记录里要能看到。
- 支持级别：两个机制登记进 `RoleSkillRegistry` 后本板变 full，无法官模式可开。
- 零场外：自爆和决斗是公开动作，不涉及 `nightInfo`。
