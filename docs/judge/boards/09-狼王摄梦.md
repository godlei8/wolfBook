# 狼王摄梦

> 摄梦人每晚让一人梦游：梦游者当晚免疫夜间死亡，但摄梦人若夜里出局，梦游者陪葬；连续两晚梦游同一人，那人出局。对面是能带人的狼王。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |

| 支持级别 | partial 🔧（摄梦人待实现） |
| 数据库 id | 9 |

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02；黑狼王同 08。

### 摄梦人 🔧 `dreamcatcher`
- 好人神职。每晚（含首夜）**必须**选择一名存活玩家（不含自己）成为梦游者，不能跳过。
- 梦游者不知道自己在梦游。
- 梦游者当晚**免疫一切夜间死亡**：狼刀无效、女巫毒无效。⚠️ 变体：有的桌只免疫狼刀，毒照死；本项目采用全免疫。
- 女巫仍被告知刀口（刀口是梦游者时，女巫会看到刀口，天亮却是平安夜——这是正常现象）。
- **摄梦人夜里出局**（被刀、被毒）→ 当晚梦游者一并出局（梦游者没有出局技能，可移交警徽）。
- **连续两晚让同一人梦游** → 第二晚结算时该玩家出局（梦游致死，同样没有出局技能）。所以摄梦人每晚必须换人，否则等于杀人。
- 摄梦人白天被放逐 → 没有任何连带；当天夜里没有梦游者。
- 没有出局技能。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 梦游 A，刀 A | A 存活（平安夜，女巫看到的刀口是 A） |
| 梦游 A，刀 A，女巫救 A | A 存活，解药照样消耗 ⚠️（变体：有的桌退回解药；本项目消耗） |
| 梦游 A，毒 A | A 存活，毒药消耗 |
| 梦游 A，刀 B | B 出局 |
| 梦游 A，摄梦人被刀 | 摄梦人、A 出局 |
| 梦游 A，摄梦人被毒 | 摄梦人、A 出局 |
| 梦游 A，摄梦人被刀且女巫救了摄梦人 | 都存活 |
| 第二晚仍梦游 A | A 出局（第二晚结算时），即使当晚没人刀它 |
| 梦游狼王，狼王被狼队自刀 | 狼王存活（免疫） |
| 梦游猎人，摄梦人被刀 | 猎人连坐出局，不能开枪 |
| 摄梦人白天被放逐 | 无连带 |

## 6. 特殊判定

- **梦游者免疫狼刀，狼队知道吗**：不知道，天亮只公布平安夜；狼队会怀疑女巫救了或守卫守了。
- **摄梦人第一晚梦游预言家，第二晚必须换**：是，否则预言家出局。
- **摄梦人把狼梦游了**：狼当晚免死（没人会刀它），没有坏处，但浪费一晚。
- **摄梦人被狼王带走**：白天出局，无连带。
- **狼王被放逐带走摄梦人**：同上，当晚没有梦游者。

## 7. 电子法官实现要点

- 新增机制 `dreamcatcher`：步骤 `DREAM`，优先级 1（和守卫同级，在狼之前），动作 `dream`（必选，不提供 `none`；超时未选时系统随机选一名非自己的存活玩家，并记一条 judge_only 事件）。`status_json.dreamSeat`、`lastDreamSeat`。
- `NightResolver`：梦游者从当晚死亡名单里移除（刀、毒都移除，药照常消耗）；摄梦人在死亡名单里 → 梦游者加入，`cause = dream`；`dreamSeat == lastDreamSeat` → 梦游者加入，`cause = dream_twice`。连坐出局跳过出局技能。
- `nightInfo`：摄梦人本人 `dreamSeat` / `lastDreamSeat`（手机上禁止选同一人，或允许但红字警告「会致死」——本项目禁止）。梦游者不下发任何信息。
- 女巫的 `knifeSeat` 照常下发刀口，不管刀口是否梦游。
