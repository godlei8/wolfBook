# 预女猎白（标准十二人局）

> 最经典的十二人板，所有面杀规则的基准。新手第一局、教学局都用它。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |
| 好人阵营 | 预言家、女巫、猎人、白痴（神职 4）+ 平民 × 4 |
| 狼人阵营 | 狼人 × 4 |
| 胜利条件 | 屠边 |
| 支持级别 | ✅ full（无法官模式可开） |
| 数据库 id | 2 |

## 2. 角色与技能

### 预言家 ✅ `seer`
- 每晚查验一名存活玩家，得知「好人」或「狼人」。
- 不能查验自己；可以重复查验同一人（没意义）。
- 查验结果只有预言家自己知道，天亮后他说不说、说真说假都随意。

### 女巫 ✅ `witch`
- 一瓶解药、一瓶毒药，整局各一次。
- 每晚被告知当晚刀口（狼队空刀则告知「平安」），可以选择用解药救刀口的人、或用毒药毒一名存活玩家、或都不用。
- 一晚只能用一瓶（救了就不能毒，毒了就不能救）。
- 自救：本板默认**不能自救**；后台可设成「首夜可以自救」。
- 解药用完后每晚仍被告知刀口。

### 猎人 ✅ `hunter`
- 出局时（被刀、被放逐、被狼王 / 猎人带走）可以翻牌开枪，带走任何一名存活玩家。
- 被毒出局、被法官点杀**不能**开枪。夜里被毒，天亮时法官问他是否开枪，他只能「确认」。
- 不开枪也可以（放弃）。开枪在遗言之前。
- 被猎人带走的玩家：白天有遗言；夜里带走（猎人首夜被刀、天亮开枪）的人也有遗言，因为是在白天公布的。⚠️ 变体：有的桌夜间被带走者无遗言。

### 白痴 ✅ `idiot`
- 被放逐时翻牌：不出局，但从此失去投票权，仍然可以发言、上警（如果还在第一天）。
- 翻牌后再次被放逐就出局（这次没有免死）。
- 夜里被刀、被毒照样死，不能翻牌。
- 被猎人 / 狼王带走照样死。
- ⚠️ 翻牌的白痴是警长时：警徽保留，但他的投票权没了，所以 1.5 票也没了，只保留定发言顺序和归票的权力。变体：有的桌翻牌即警徽流失。

### 平民 ✅ `villager`
- 没有技能，靠听、看、投票。

### 狼人 ✅ `wolf`
- 首夜互认；每晚共同刀一人，可空刀、可自刀。
- ✅ 白天发言阶段可以自爆（见 README 2.8）。
- 被预言家查验为狼人。

## 3. 夜间流程

| 步 | 台词 | 做什么 | 判定 |
|---|---|---|---|
| 1 | 天黑请闭眼 | 全体闭眼 | |
| 2 | 狼人请睁眼，请统一意见刀人 | 狼队互认、选刀口 | 多数定刀口，平票随机，可空刀 |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了，你要用解药吗？你要用毒药吗？ | 女巫看到刀口，选救 / 毒 / 不用 | 一晚一瓶；自救按板子设置 |
| 4 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 预言家指人 | 法官比好人 / 狼人手势 |
| 5 | 预言家请闭眼。猎人请睁眼，确认你今晚的开枪状态 | 猎人看手势 | 被毒 = 不能开枪（法官比叉） |
| 6 | 猎人请闭眼。天亮了 | 公布出局 | |

猎人这一步是线下为了不暴露女巫是否用毒而固定念的；电子法官里猎人在手机上看到「今晚能否开枪」即可。

## 4. 白天流程

和 README 2.3 到 2.8 完全一致，没有本板特殊项。第一天有警长竞选。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 刀 A，女巫救 A | A 存活，平安夜 |
| 刀 A，女巫毒 B | A、B 都出局 |
| 刀 A，女巫救 A 并想毒 B | 不允许（一晚一瓶） |
| 狼空刀，女巫毒 B | B 出局 |
| 狼刀女巫本人 | 女巫被告知刀口是自己；默认不能自救，板子开了首夜自救且是首夜才能救 |
| 狼刀猎人 | 猎人出局，天亮开枪 |
| 女巫毒猎人 | 猎人出局，不能开枪 |
| 猎人被放逐 | 开枪，然后遗言 |
| 白痴被放逐（第一次） | 翻牌，不出局，失去投票权 |
| 白痴被放逐（第二次） | 出局，有遗言 |
| 猎人开枪带走白痴 | 白痴出局，不能翻牌 |

## 6. 特殊判定

- **猎人被放逐时开枪带走警长**：警长先移交警徽，再发表遗言；顺序是猎人开枪 → 被带走者处理警徽 → 被带走者遗言 → 猎人遗言。⚠️ 遗言先后各桌不一，本项目按出局顺序：先出局者先说。
- **狼人自爆后女巫当晚能不能毒**：可以，自爆只跳过白天，夜里一切照常。
- **首夜女巫救了刀口，狼人和女巫都以为对方是谁**：不公布死因，天亮只说平安夜。
- **最后一只狼被放逐，同时猎人也被狼王带走**：本板没有狼王，不涉及。
- **四狼全部出局时好人直接胜**，哪怕女巫还有毒药没用。
- **只剩 1 神 + 若干民 vs 狼**：屠边，神职全出局狼人才算赢，所以要看最后一个神职。

## 7. 电子法官实现要点

- 阵容机制全有：`seer` `witch` `hunter` `idiot` `villager` `wolf`。支持级别 full，无法官模式可开。
- 夜间顺序：引擎默认（狼队 2 → 女巫 3 → 预言家 4 → 猎人 5），本板没有守卫，第 1 步为空，不必特别配置 `nightOrder`。
- `nightInfo` 只给本人：狼队的 `teammateSeats` / `wolfPicks`；女巫的 `knifeSeat`、`antidote`、`poison`；预言家的 `checkedSeat` / `checkResult`；猎人的「今晚能否开枪」。
- 出局待办：猎人 `hunter_shot`（被毒只有确认）、白痴翻牌（放逐时自动触发，不需要询问）、警徽移交。
- 本板是回归测试的基准：`JudgeFlowIntegrationTests` 用它跑无法官模式整局。

## 8. 变体

- **预女猎守**：白痴换守卫，见 03 的守卫规则。
- **九人预女猎 / 预女守**：3 狼 3 民 + 3 神，见 03。
- **六人局 / 八人局**（新手）：2 狼 + 预言家 + 女巫 + 平民若干，没有警长，不在本库范围。
