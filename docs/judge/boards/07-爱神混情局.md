# 爱神混情局（丘比特局）

> 第三方板：爱神首夜把两人连成情侣，情侣同生共死。狼人和好人结成的情侣变成第三方，要熬到全场只剩他们俩才赢。三方博弈，胜负判定最复杂。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |
| 好人阵营 | 预言家、女巫、猎人（神职 3）+ 平民 × 4 |
| 狼人阵营 | 狼人 × 4 |
| 第三方 | 爱神（见 2 节关于它阵营的说明） |
| 胜利条件 | 屠边 + 情侣胜 |
| 支持级别 | partial 🔧（爱神与第三方胜利待实现） |
| 数据库 id | 7 |

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02。

### 爱神（丘比特）🔧 `cupid`
- **首夜最先行动**：选择两名玩家成为情侣（可以包含自己）。整局只有这一次。
- 情侣当晚互相睁眼认识对方（法官轻拍两人）。情侣知道彼此座位，不知道彼此身份。
- 情侣**同生共死**：一人出局（任何方式、任何时间），另一人立即殉情出局。殉情者没有出局技能（猎人殉情不能开枪），可移交警徽，夜间殉情无遗言、白天殉情有遗言。
- 情侣阵营：
  - 两人同为好人：仍是好人，和好人一起赢；
  - 两人同为狼人：仍是狼人；
  - 一狼一好（「混情」）：两人**脱离原阵营**成为第三方，胜利条件是**场上只剩他们两人**（其他所有人出局）。此时狼队仍把那只狼当队友（他继续参与刀人），但他的目标已经变了。
- 爱神本人：⚠️ 标准规则里丘比特是**好人神职**，连完就是普通神职（没有后续技能），和好人一起赢；只有他把自己连进混情侣才变第三方。**本项目角色表把爱神标为「第三方」**，这会让屠边计算不把它算进神职——需要拍板二选一：
  - A（推荐，标准）：爱神是好人神职，算屠边里的「神」；
  - B（现状）：爱神是独立第三方，不算神也不算民，自己的胜利条件 = 好人胜或情侣胜任一达成时存活。
  本文其余部分按 A 写。
- 被预言家查验：爱神报好人；混情侣中的狼仍报狼人（查验看牌不看阵营变化）。
- 爱神没有出局技能。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 情侣 A（好）–B（好），A 被刀 | B 殉情，两人出局 |
| 情侣 A（狼）–B（好），A 被放逐 | B 殉情；第三方全灭 |
| 情侣 A（狼）–B（好），场上只剩 A、B | **情侣胜**（第三方） |
| 情侣 A（狼）–B（好），其他狼全出局，还有好人存活 | 游戏继续：好人阵营「狼人为 0」不成立（A 仍是狼牌，但他已是第三方）⚠️ 见 6 |
| 混情侣中的狼 A 和狼队一起刀了 B | B 死，A 殉情 |
| 情侣中有猎人，另一人出局 | 猎人殉情，不能开枪 |
| 爱神把自己和狼连成情侣 | 爱神变第三方 |
| 女巫救了被刀的情侣之一 | 两人都活 |
| 情侣 A 被放逐，B 是警长 | B 殉情前移交警徽 |

## 6. 特殊判定

- **屠边怎么算混情侣**：⚠️ 本项目定为：混情侣的两人**不再计入**狼人阵营和好人阵营的存活数。于是：剩余狼队（不含情侣狼）为 0 → 好人胜（情侣同时判负）；神或民（不含情侣好人）清零 → 狼人胜；全场只剩情侣 → 情侣胜。三个条件每次出局后同时检查，先满足的生效。变体：有的桌情侣狼仍算狼人，必须一起清掉好人才赢。
- **好人胜时情侣算赢还是输**：输（情侣的胜利条件只有「只剩两人」）。
- **情侣都是好人，好人胜**：情侣算赢。
- **情侣知道对方是狼吗**：不知道，只知道座位；第三方情侣要靠白天互相试探。
- **爱神能不能不连**：不能，首夜必须连。
- **爱神选的人当晚被刀**：另一人殉情；首夜就可能双死。

## 7. 电子法官实现要点

- 新增机制 `cupid`：只在第一夜有步骤 `CUPID`，优先级 -3（最先），动作 `link`（`targetSeatNos` 两个，可含自己）、必选（超时随机）。写入两人 `status_json.loverSeat`；两人的 `nightInfo` 立即下发 `loverSeat`（整局可见）。
- 殉情钩子：任何出局 → 若 `loverSeat` 存活 → 连带出局 `cause = lover`（跳过出局技能，允许移交警徽），再判胜负。
- 阵营：连接时若两人 `faction` 不同，把两人 `judge_room_players.faction` 改为 `第三方`（座位级阵营，角色表不改；狼队成员资格 `wolfTeam` 保留，他仍参与刀人、仍在 `teammateSeats` 里）。
- `WinJudge` 增加第三方分支：存活名单只剩情侣两人 → `winnerCamp = lovers`；狼人 / 好人判定排除 `faction = 第三方` 的座位。结果页胜方展示要支持「情侣胜」。
- 爱神本人阵营按拍板结果设置角色表 `faction`（A 方案改回好人 + 神职）。
- 这是唯一涉及第三方胜利的板，建议最后做；在此之前只开有法官模式，法官手动判胜负。
