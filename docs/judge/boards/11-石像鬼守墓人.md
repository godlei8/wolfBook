# 石像鬼守墓人

> 信息板：石像鬼每晚查人的具体身份，守墓人每晚得知昨天被放逐者的阵营。双方都在攒信息，谁先说服全场谁赢。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |
| 好人阵营 | 预言家、女巫、猎人、守墓人（神职 4）+ 平民 × 4 |
| 狼人阵营 | 狼人 × 3 + 石像鬼 |
| 胜利条件 | 屠边 |
| 支持级别 | partial 🔧（石像鬼、守墓人待实现） |
| 数据库 id | 11 |

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02。

### 石像鬼 🔧 `gargoyle`
- 狼人阵营，但**不和狼队一起睁眼**：狼队不知道谁是石像鬼，石像鬼也不知道谁是狼（要靠自己查）。
- 每晚单独睁眼，查验一名存活玩家的**具体身份**（角色名：预言家 / 女巫 / 狼人……）。可以查自己以外的任何人。
- 不参与狼队刀人。
- **其他狼人全部出局后**，石像鬼从下一晚起可以刀人（接管狼刀），仍然不能和别人商量。
- 不能自爆。
- 被预言家查验为**狼人**。
- 没有出局技能。
- 屠边：石像鬼算狼人阵营，好人要连石像鬼一起清掉才赢。

### 守墓人 🔧 `gravekeeper`
- 好人神职。每晚（从第二晚起）得知**当天白天被放逐出局**的玩家是好人还是狼人。
- 只看放逐：被猎人 / 狼王带走、被毒、自爆、殉情的都不算；当天平票没人放逐就没有信息。
- 被放逐的白痴翻牌免死不算出局，守墓人得不到信息。
- 第一晚没有信息（还没放逐过）。
- 守墓人不知道被放逐者的具体角色，只知道阵营。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 石像鬼请睁眼，今晚你要查验谁？ | 石像鬼指人，法官展示该玩家身份牌 |
| 2 | 石像鬼请闭眼。狼人请睁眼，请统一意见刀人 | 狼队选刀口（石像鬼不睁眼） |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 救 / 毒 |
| 4 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 查 |
| 5 | 预言家请闭眼。守墓人请睁眼，今天被放逐的是（好人 / 狼人）| 法官比手势；首夜或无放逐则比「无」 |
| 6 | 守墓人请闭眼。猎人请睁眼，确认开枪状态 | |
| 7 | 猎人请闭眼。天亮了 | |

狼队全灭后第 2 步改为「石像鬼请睁眼，今晚你要刀谁？」，查验步照常保留在前。

## 4. 白天流程

同 README。守墓人的信息来自白天的放逐结果，法官要记下每天被放逐者的阵营。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 石像鬼查验预言家 | 得知「预言家」 |
| 石像鬼查验狼人 | 得知「狼人」（这是它找到队友的唯一方式） |
| 预言家查验石像鬼 | 「狼人」 |
| 狼队刀石像鬼（不知道它是队友） | 石像鬼死 |
| 三狼全出局，石像鬼存活 | 下一晚起石像鬼刀人，女巫照常得知刀口 |
| 石像鬼接管刀人期间被守卫守住（本板无守卫，同类板参考） | 守护照常生效 |
| 当天放逐狼人 | 守墓人当晚得知「狼人」 |
| 当天平票无放逐 | 守墓人无信息 |
| 当天白痴翻牌 | 守墓人无信息 |
| 当天猎人被放逐并开枪带走 A | 守墓人只知道猎人的阵营（好人），不知道 A 的 |
| 石像鬼被放逐 | 守墓人当晚得知「狼人」 |

## 6. 特殊判定

- **石像鬼查验到队友后能不能夜里给暗号**：不能，夜里不许交流；它只能白天靠发言暗示。
- **狼队全灭当晚石像鬼能否立刻刀人**：不能，从**下一晚**开始（狼队是白天被放逐的，当晚就可以；狼队最后一只是夜里死的，要等下一晚）。本项目统一为：狼队清零发生在白天 → 当晚可刀；发生在夜里 → 下一晚可刀。
- **只剩石像鬼一只狼，屠边**：它每晚一刀，好人要尽快投它。
- **守墓人上警报身份**：常见打法，狼队会优先刀它。

## 7. 电子法官实现要点

- 新增机制 `gargoyle`：`faction = 狼人` 但 `wolfTeam = false`（不进狼队步、`teammateSeats` 不下发也不包含它）；单独夜间步骤 `GARGOYLE_CHECK`，优先级 0.5（最先，在守卫之前也行，它不影响别人），动作 `check`，`nightInfo` 下发 `checkedSeat` / `checkedRole`（角色名）。当 `aliveWolfTeam == 0 && gargoyleAlive` 时，狼队步由石像鬼单独走，动作 `kill` / `none`。
- 预言家查验：`faction = 狼人` → 报狼人（现有逻辑已覆盖）。
- 新增机制 `gravekeeper`：夜间步骤 `GRAVE_LOOK`，优先级 4.6（预言家后、猎人前），动作 `confirm`；`nightInfo` 下发 `exiledFaction`（好人 / 狼人 / 无）。信息来源：当天 `vote_result` 记录的放逐者（`cause = exiled`），白痴翻牌不算。
- `WinJudge`：石像鬼 `faction = 狼人`，现有判定自然覆盖；但「狼队全灭」判断要区分「狼队成员为 0」和「狼人阵营为 0」。
- 两个机制登记后本板 full。
