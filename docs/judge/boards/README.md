# 面杀板子规则库

给电子法官开发用的规则底稿：一个板子一个文档，写清阵容、每个角色的技能边界、夜间顺序、白天流程、结算交互和争议判定。所有板子共用的流程框架写在本文第二部分，各板子文档只写和框架不同的地方。

规则以线下主流面杀（JY 规则体系 / 网易狼人杀官方裁定）为底，和本项目电子法官已经拍板的全局规则对齐。每条规则前面的标记：

| 标记 | 含义 |
|---|---|
| ✅ | 电子法官引擎已实现（`service/judge/`） |
| 🔧 | 引擎还没有这个机制，文档里写的是实现时要遵守的规则 |
| ⚠️ | 各地裁定不一致，文档给出本项目采用的版本，并列出常见变体；实现前最好再确认一次 |
| 📌 | 本项目原创角色或本项目特有的裁定，没有外部标准 |

## 二、通用流程框架

下面这些所有板子一样，各板子文档不再重复。

### 2.1 开局

1. 法官（或系统）核对人数，随机发身份，每人看牌后盖牌。
2. 首夜前所有人不得交流身份信息。
3. 「天黑请闭眼」后进入第一夜。

### 2.2 夜间框架

每一夜按板子的夜间顺序逐个叫醒角色，每一步的通用规则：

- ✅ 每一步固定时长，角色不在场（已出局）照样走完整时长，台词照念，不让别人从切步快慢推断身份（零场外）。
- ✅ 狼队合成一步：全部狼队成员同时睁眼、互认、商量刀口；意见不一按多数，平票随机，可以空刀，可以自刀。
- ✅ 女巫每晚都会被告知刀口，解药用完也照样告诉；一晚只能用一瓶药；自救规则跟板子走（默认不能，可设首夜可以）。
- ✅ 守卫可以守自己，不能连续两晚守同一人，守不住毒；同守同救算死。
- ✅ 预言家查验只报「好人」「狼人」，功能狼一律报狼人；机械狼报好人（见其板子文档）。
- 夜间没有任何角色的操作被公开；各人只在自己的手机上看到自己的信息（`nightInfo`）。

**默认夜间顺序**（板子没配 `nightOrder` 时引擎按机制优先级生成）：

```
守卫 → 狼队（狼人 / 狼王 / 白狼王 / 狼美人 / 梦魇 一起睁眼）→ 女巫 → 预言家 → 猎人确认 → 其他
```

各板子有额外角色时，在板子文档里给出完整顺序。排序原则：**先行动的角色不能看到后行动角色的结果**：守卫在狼前（守卫不知道刀口），女巫在狼后（她要看刀口），预言家在女巫后（查验不受女巫影响），最先动的是改变「目标」的角色（魔术师、梦魇）。

### 2.3 天亮

1. 公布昨夜结果：「昨晚是平安夜」或「昨晚 X 号、Y 号出局」，不公布死因（被刀 / 被毒 / 奶穿都只说出局）。
2. 夜里出局的玩家依次处理出局技能（猎人开枪、狼王开枪、警徽移交），再发表遗言（只有首夜出局者有遗言，见 2.7）。
3. 第一天先竞选警长（2.4），再进入发言。

### 2.4 警长竞选（只在第一天）

| 步骤 | 规则 |
|---|---|
| 报名 | 天亮后所有存活玩家可以上警，报名时间到了不能再加。 |
| 警上发言 | 上警者按法官定的顺序（随机起点，顺时针）依次发言，每人一轮。 |
| 退水 | 发言结束后上警者可以退水；退水的人不再参选，但保留投票权。 |
| 投票 | **只有警下的玩家投票**，上警者不投。每人一票投给一名候选人，可弃票。 |
| 平票 | 平票者 PK：各再发言一轮，警下再投一次；再平票本局**无警长**。 |
| 全退水 / 无人上警 | 本局无警长。 |
| 警长竞选中有狼自爆 | ✅ 📌 **双爆吞警徽**（用户 2026-11-04 拍板）：第一天警上发言时有人自爆，竞选挪到第二天——先公布昨夜死讯、处理死者技能和遗言，然后入夜；第二天天亮后、公布第二晚死讯之前接着竞选，第一天上警、没退水、还活着的人仍是候选人，不再报名。第二天竞选时再有人自爆，警徽流失，本局不再竞选。报名阶段不能自爆。变体：有的桌第一次自爆就吞警徽。 |

警长权力：✅ 投票算 1.5 票；决定白天发言顺序（警左 / 警右、从谁开始）；归票时可以总结；出局时（无论白天黑夜）可以把警徽移交给任何一名存活玩家，或撕掉（本局之后无警长）。⚠️ 被毒死的警长也可以移交（移交不是技能，不受毒影响）。

### 2.5 白天发言

- 发言顺序：有警长时警长定；没有警长时从昨夜最后一名出局者的下一位开始（死左 / 死右由法官定，本项目固定死右即顺时针）；平安夜从警长或法官随机指定的位置开始。
- 每人一轮，计时（板子 `judgeRules` 定时长，默认 90 秒，警上发言 60 秒）；到时只提示，不强制打断。
- 发言阶段狼人可以自爆（2.8）；骑士可以翻牌决斗（见对应板子）。

### 2.6 放逐投票

- 所有存活且有投票权的玩家同时投票，每人一票，可弃票；警长 1.5 票。
- 得票最多者被放逐；平票者 PK：平票者各再发言一轮，然后**只能投给平票者**，其他人投票；再平票当天无人出局。
- 票型公开（谁投了谁）。
- 被放逐者先处理出局技能（白痴翻牌、猎人开枪、警徽移交），再发表遗言。
- 投票结束天黑；投票阶段不能自爆。

### 2.7 遗言

| 出局方式 | 有没有遗言 |
|---|---|
| 首夜（第一晚）出局 | 有 |
| 第二晚起夜里出局 | 没有 |
| 白天被放逐 | 有 |
| 白天被猎人 / 狼王开枪带走 | 有 |
| 被骑士决斗 | 没有（直接入夜） |
| 被白狼王自爆带走 | 没有（直接入夜） |
| 狼人自爆 | 没有 |
| 殉情 / 被动出局（狼美人魅惑、摄梦人连坐、情侣） | 夜里没有；白天跟随放逐一起出局的有 |

⚠️ 变体：网易线上版本所有夜间死亡都没有遗言；JY 线下规则只有首夜死亡有遗言。本项目采用后者。

### 2.8 自爆

✅ 电子法官已实现（2026-11-04，狼人、黑狼王；`POST /api/judge/rooms/{roomId}/self-destruct`）。

- 只有狼人阵营、且文档里标明「可以自爆」的角色可以自爆；自爆是狼人技能机制自带的技能（📌 用户 2026-11-04 拍板：不做成开关），现在狼人、黑狼王的机制带自爆。只能在**白天发言阶段**（含警上发言，不含上警报名），投票阶段不能。
- 自爆者立即出局、没有遗言、当天不再发言和投票，直接入夜。公告只说「X号自爆」。
- 在警长竞选阶段自爆：双爆吞警徽，见 2.4。
- 自爆不触发出局技能（狼王自爆不能带人；白狼王例外，它的技能就是自爆带人）；自爆的警长可以移交或撕掉警徽。

### 2.9 出局技能的处理顺序

同一时刻多人出局时（比如狼美人被放逐、被魅惑者跟着出局），按这个顺序结算，✅ 引擎用 `skill_pending` 待办队列逐个处理：

1. 先结算直接出局者（被放逐 / 被刀 / 被毒）。
2. 由此引发的连带出局（殉情、梦游者、情侣）。
3. 出局者的主动技能询问：猎人 / 狼王开枪 → 被带走的人再进入 1。
4. 警徽移交。
5. 遗言。
6. 每一次有人出局后立即判胜负（2.10），达成即结束，后面的技能不再处理。

### 2.10 胜负

| 胜利条件 | 狼人阵营胜 | 好人阵营胜 |
|---|---|---|
| 屠边（默认） | 存活神职为 0 **或** 存活平民为 0 | 存活狼人阵营为 0 |
| 屠城 | 存活神职 + 平民为 0 | 存活狼人阵营为 0 |

- ✅ 狼人阵营按 `faction = 狼人` 算：狼人、狼王、黑狼王、白狼王、狼美人、石像鬼、机械狼、梦魇之影都算，狼人要全出局好人才赢。
- ✅ 双方条件同一次出局里同时达成算狼人胜。
- ✅ 翻牌后的白痴仍算存活神职。
- 第三方（爱神的情侣）另有胜利条件，见 07。

### 3.2 连带出局的统一规则

狼美人魅惑、织梦人连梦、摄梦人梦游、情侣殉情都是「别人出局带着我出局」，引擎用同一套处理：`cause` 标明来源；**跳过出局技能**（猎人 / 狼王不开枪，白痴不翻牌）；**允许移交警徽**；遗言按出局时段（夜里无、白天有）；连带出局后**再判一次胜负**。
