# 狼王守卫

> 预女猎守四神对三狼一狼王。狼王出局能带人，好人投狼要先想清楚谁会被带走。线下最常见的进阶板之一。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |
| 好人阵营 | 预言家、女巫、猎人、守卫（神职 4）+ 平民 × 4 |
| 狼人阵营 | 狼人 × 3 + 黑狼王 |
| 胜利条件 | 屠边 |
| 支持级别 | ✅ full |
| 数据库 id | 8 |

本项目里「狼王」和「黑狼王」是同一个机制（`wolf_king`），库里这块板用的角色叫黑狼王。

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02；守卫同 03。

### 黑狼王 ✅ `wolf_king`
- 夜里和狼队一起睁眼刀人，是普通狼队成员。
- 出局时（被放逐、被猎人开枪带走、被刀——自刀或狼队平票刀到自己）可以翻牌开枪，带走任何一名存活玩家。
- **被女巫毒死不能开枪；被法官点杀不能开枪。**
- ✅ 可以自爆，但**自爆不能带人**（只有白狼王自爆能带人）。
- 被预言家查验为狼人。
- 和猎人互相带走：猎人被放逐开枪带走狼王 → 狼王可以开枪再带走一人（狼王不是被毒死的）。反过来狼王被放逐带走猎人 → 猎人也可以开枪。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 守卫请睁眼，今晚你要守护谁？ | 守 |
| 2 | 守卫请闭眼。狼人请睁眼（狼王一起），请统一意见刀人 | 狼队含狼王选刀口 |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 救 / 毒 |
| 4 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 查 |
| 5 | 预言家请闭眼。猎人请睁眼，确认你的开枪状态 | 猎人看能否开枪 |
| 6 | 猎人请闭眼。狼王请睁眼，确认你的开枪状态 | 狼王看能否开枪（被毒 = 不能） |
| 7 | 狼王请闭眼。天亮了 | |

线下为了不暴露女巫用没用毒，猎人和狼王的确认步每晚都念。✅ 电子法官里狼王**没有单独的夜间步骤**（和狼人一起行动），能否开枪在天亮的技能询问里体现（被毒了只有「确认」按钮）。

## 4. 白天流程

同 README。狼王被放逐时的处理顺序：票型公布 → 狼王翻牌选择带走谁（或放弃）→ 被带走者如是猎人则再开枪 → 警徽移交 → 遗言（先狼王后被带走者）。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 狼王被放逐 | 可带走一人 |
| 狼王被猎人枪杀 | 可带走一人 |
| 狼王被毒 | 出局，不能带人 |
| 狼王被刀（自刀 / 狼队平票刀中） | 出局，天亮可带走一人 |
| 狼王自爆 | 出局，不能带人，直接入夜 |
| 狼王被守卫守住、狼队刀狼王 | 狼王存活（守卫不知道守的是狼） |
| 狼王带走猎人 | 猎人可以开枪 |
| 狼王带走白痴 | 白痴出局，不能翻牌 |
| 狼王带走狼队友 | 允许（引擎不限制），一般没人这么做 |
| 最后一只狼是狼王且被放逐 | 好人已胜，狼王**不能**再开枪 |
| 狼王带走最后一个神职 | 狼王出局的同一次结算里神职清零 → 狼人胜（同时达成算狼胜） |

## 6. 特殊判定

- **狼王在第一天被放逐带走预言家**：合法，这是狼王局最常见的翻盘点。
- **狼王被放逐，带走警长**：警长移交警徽后再遗言。
- **猎人、狼王同一天互相带走形成链**：按 README 2.9 的待办队列逐个处理，每一步出局后都判一次胜负。
- **狼王被毒当晚狼队刀了猎人**：天亮两人都出局，猎人能开枪、狼王不能。
- **狼王能不能带走自己**：不能。

## 7. 电子法官实现要点

- 阵容机制：`seer` `witch` `hunter` `guard` `villager` `wolf` `wolf_king`，full。
- `Mechanic.canShoot()` 对猎人和狼王为真，出局技能共用 `hunter_shot` 待办与事件类型，公告统一为「X 号发动技能，带走了 Y 号」。
- 被毒的狼王：`NightResolver` 标记「不能开枪」，待办里只有确认。
- `WinJudge` 在每次出局后判定，最后一只狼出局后不再给狼王开枪机会。
- 种子板子 8 就是本板；老库用 `deploy/sql/2026-11-02-wolf-king-mechanic.sql` 补黑狼王机制。
- 联调：`scripts/judge-e2e.mjs wolfking`。
