# 狼王魔术师

> 魔术师每晚交换两名玩家的号码牌，当晚所有针对号码的技能对调：狼以为刀了 3 号，实际死的是 7 号。信息最混乱的板，对法官要求最高。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02；黑狼王同 08。

### 魔术师 🔧 `magician`
- 好人神职。每晚（含首夜）可以选择**两名**存活玩家交换号码牌，当晚生效，天亮恢复。可以不交换。
- 可以交换含自己在内的任意两人。⚠️ 变体：有的桌不能换自己；本项目允许。
- 不能连续两晚交换**同一名**玩家（两人中任一人和上一晚重复都不行）。
- 交换后，当晚**所有以号码为目标的技能对调**：
  - 狼队刀 A → 实际刀到 B；
  - 女巫被告知的刀口是**实际倒下的人**（B）；女巫救 / 毒「A 号」→ 实际作用到 B；
  - 预言家查验 A → 得到 B 的阵营，但法官只说「好人 / 狼人」，预言家以为是 A 的；
  - 守卫（同类板）守 A → 实际守 B。
- 被交换的两人不知道自己被交换。
- 魔术师自己的行动不受交换影响（他知道自己换了谁）。
- 没有出局技能。

**原则**：交换只改「指向」，不改人。谁被刀谁死，死的是真人；被告知的信息（刀口、查验）按真实情况给，只是行动者以为目标是另一个号码。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 魔术师请睁眼，今晚你要交换哪两名玩家？ | 法官记下 A↔B |
| 2 | 魔术师请闭眼。狼人请睁眼（狼王一起），请统一意见刀人 | 狼指 X；法官换算真实目标 X′ |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X′ 号倒下了…… | 女巫看到真实刀口；她指的号码也要换算 |
| 4 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 法官按换算后的真实目标比手势 |
| 5 | 预言家请闭眼。猎人请睁眼，确认开枪状态 | |
| 6 | 猎人请闭眼。狼王请睁眼，确认开枪状态 | |
| 7 | 狼王请闭眼。天亮了 | |

魔术师必须最先：之后所有步骤法官都要做换算。线下法官要在纸上写一行「本晚 A=B」，每次有人指号码就查一次。

## 5. 结算细则（当晚交换 3↔7）

| 行动 | 实际效果 |
|---|---|
| 狼刀 3 | 7 倒下 |
| 女巫被告知刀口 | 「7 号」 |
| 女巫救 7 | 救到 3（没被刀）→ 7 照死，解药消耗 ⚠️ 见下 |
| 女巫救 3 | 救到 7 → 7 存活 |
| 女巫毒 3 | 7 被毒 |
| 预言家查 3 | 得到 7 的阵营 |
| 狼刀 5（和交换无关） | 5 倒下，女巫被告知 5 |
| 魔术师换了自己（魔术师是 3 号），狼刀 3 | 7 倒下 |
| 狼王（7 号）被刀：狼刀 3 | 狼王倒下，天亮可开枪 |

⚠️ **女巫救人的争议**：女巫看到的刀口是真实的 7 号，她说「救 7」，按换算救到 3，7 照死。线下很多桌认为这对女巫太不公平，改成「女巫的解药作用于刀口本人，不换算」。本项目定为：**女巫的解药不换算（直接救刀口本人），毒药换算**。实现时按这条来。

## 6. 特殊判定

- **狼刀的人是被交换的，女巫救了，守卫（同类板）又守了换算后的人**：按真实目标算同守同救。
- **预言家查验被换的人，查到狼**：预言家报的是他指的号码，法官不纠正；这就是魔术师制造的信息差，魔术师白天要出来解释。
- **魔术师第一晚就被刀**：当晚的交换照常生效。
- **交换的两人中有一人当晚被放逐已出局**：不能选已出局者。
- **狼队刀狼队友（自刀）被换到好人身上**：好人死，狼队不知道。

## 7. 电子法官实现要点

- 新增机制 `magician`：步骤 `SWAP`，优先级 -2（最前，在梦魇之前——如果同板有梦魇，恐惧也要换算；但本库里两者不同板），动作 `swap`（`targetSeatNos` 两个）/ `none`；校验不同、都存活、和 `lastSwap` 无交集。
- `NightResolver` 增加「目标重映射」：结算前把当晚所有动作的 `targetSeatNo` 经 `swapMap` 换算（解药除外，按第 5 节的裁定），再走现有结算；`nightInfo.knifeSeat` 给女巫**真实**刀口；预言家的 `checkResult` 按换算后目标算，`checkedSeat` 仍显示他指的号码。
- 事件记录：原始目标和换算后目标都记（judge_only），对局记录结束后全场可见，玩家复盘才看得懂。
- 公告照常只报出局者。
- 这是夜间结算最复杂的机制，建议最后做；在此之前本板只开有法官模式，法官手动换算。
