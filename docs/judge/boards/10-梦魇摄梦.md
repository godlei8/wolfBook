# 梦魇摄梦

> 梦境对决：摄梦人每晚保护一人，梦魇之影每晚恐惧一人让他当晚技能失效。梦魇最先行动，恐惧到摄梦人则当晚没有梦游者。

| 项 | 值 |

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02；摄梦人同 09。

### 梦魇之影 🔧 `nightmare`
- 狼人阵营，和狼队一起睁眼刀人。
- 每晚**最先**单独睁眼，恐惧一名存活玩家（不含自己，可以是狼队友）。可以不恐惧。
- 被恐惧的玩家**当晚技能失效**：
  - 守卫 / 摄梦人 / 预言家 / 女巫被恐惧：当晚不能行动（法官照常叫他睁眼，但告诉他「你被恐惧了」，他只能闭眼）；
  - 猎人被恐惧：当晚被刀的话天亮不能开枪；
  - 平民被恐惧：没有效果。
- 不能连续两晚恐惧同一人。
- 被恐惧者天亮后知道自己昨晚被恐惧过（有技能的角色自然知道；平民不告知）。⚠️ 变体：有的桌被恐惧者白天失去投票权，本项目不采用。
- 不能自爆。⚠️ 变体：有的桌允许；本项目不允许。
- 被预言家查验为狼人。
- 没有出局技能。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 梦魇请睁眼，今晚你要恐惧谁？ | 恐惧 |
| 2 | 梦魇请闭眼。摄梦人请睁眼，今晚你要让谁梦游？ | 被恐惧则跳过（法官示意） |
| 3 | 摄梦人请闭眼。狼人请睁眼（梦魇一起），请统一意见刀人 | 选刀口 |
| 4 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 被恐惧则只听刀口不能用药 ⚠️（变体：不告知刀口；本项目仍告知） |
| 5 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 被恐惧则无结果 |
| 6 | 预言家请闭眼。猎人请睁眼，确认开枪状态 | 被恐惧或被毒 = 不能开枪 |
| 7 | 猎人请闭眼。天亮了 | |

梦魇必须第一个：恐惧要在所有技能之前生效。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 恐惧摄梦人 | 当晚无梦游者 |
| 恐惧摄梦人，且狼刀摄梦人 | 摄梦人出局，无梦游者所以无连坐 |
| 恐惧女巫，狼刀 A | 女巫看到刀口但不能救，A 出局 |
| 恐惧预言家 | 当晚无查验结果，查验机会浪费 |
| 恐惧猎人，狼刀猎人 | 猎人出局，不能开枪 |
| 恐惧猎人，猎人白天被放逐 | 可以开枪（恐惧只管当晚） |
| 恐惧狼队友 | 允许，没有意义 |
| 摄梦人梦游梦魇 | 梦魇当晚免死 |
| 摄梦人梦游 A，梦魇恐惧 A（A 是守卫，同类板） | A 既免死又不能守 |
| 连续两晚恐惧同一人 | 不允许 |
| 梦魇被毒 | 出局，当晚的恐惧已生效 |

## 6. 特殊判定

- **恐惧和梦游同一个人**：互不影响，各自生效。
- **梦魇恐惧了摄梦人，摄梦人「必须选人」的规则怎么办**：当晚免除，视为没有梦游者，也不算「连续两晚同一人」。
- **预言家被恐惧那晚能不能换人查**：不能，这一晚整个跳过。
- **梦魇是最后一只狼，被放逐**：好人胜。

## 7. 电子法官实现要点

- 新增机制 `nightmare`：狼队成员 + 单独步骤 `FEAR`，优先级 -1（在所有步骤之前，含织梦人 / 摄梦人 / 守卫），动作 `fear` / `none`，`status_json.fearedSeat` / `lastFearedSeat`。
- 被恐惧者的处理：当晚该座位的夜间步骤照常计时（零场外），但提交一律 4002「你被恐惧了」，手机上显示「今晚你的技能失效」；`NightResolver` 结算时忽略该座位的动作；猎人被恐惧 → 当晚死亡时 `canShoot = false`。
- `nightInfo`：梦魇本人 `fearedSeat`；被恐惧者 `feared: true`（天亮后仍可看到）。
- 摄梦人被恐惧时不触发「必选」的随机兜底。
- 与摄梦人（09）一起实现后本板 full。
