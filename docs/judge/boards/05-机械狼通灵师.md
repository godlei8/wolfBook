# 机械狼通灵师

> 没有预言家的板：好人靠通灵师查具体身份；狼人方的机械狼查验为好人，还能继承出局神职的技能。

## 1. 配置

| 项 | 值 |
|---|---|
| 人数 | 12 |
| 好人阵营 | 通灵师、女巫、猎人、守卫（神职 4）+ 平民 × 4 |
| 狼人阵营 | 狼人 × 3 + 机械狼 |
| 胜利条件 | 屠边 |
| 支持级别 | partial 🔧（机械狼、通灵师待实现） |
| 数据库 id | 5 |

## 2. 角色与技能

女巫、猎人、平民、狼人同 02；守卫同 03。本板**没有预言家**，查验位是通灵师。

### 通灵师 🔧 `psychic`
- 好人神职。每晚查验一名存活玩家的**具体身份**（角色名）。
- 不能查自己。
- 查验机械狼得到「机械狼」（通灵师看的是牌，不是阵营判定）。
- 没有出局技能。

### 机械狼 🔧 `mech_wolf`
- 狼人阵营。夜里和狼队一起睁眼**互认**，但**不参与刀人**（刀口由其他狼决定，机械狼只能看）。⚠️ 变体：有的桌狼队不知道机械狼，机械狼单方面知道狼队。本项目采用互认。
- 被预言家查验为**好人**（本板没有预言家，同类板参考）；被通灵师查验为「机械狼」。
- **继承技能**：当好人神职出局（任何方式）时，机械狼从下一晚起获得该神职的技能（通灵师的查验、女巫剩余的药、守卫的守护、猎人的开枪）。⚠️ 变体很多，本项目定为：
  - 只继承**第一个**出局的神职，之后再有神职出局不再变化；
  - 继承女巫时，拿到的是女巫**剩余**的药（用过的不再有）；
  - 继承猎人时，机械狼出局可开枪（被毒除外）；
  - 继承守卫时，受不能连守的限制，从自己第一次守开始算。
- **其他狼人全部出局后**，机械狼可以在夜里刀人。
- 不能自爆。
- 继承的技能和刀人可以同时拥有（狼队全灭后既刀人又用技能）。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 守卫请睁眼，今晚你要守护谁？ | 守 |
| 2 | 守卫请闭眼。狼人请睁眼（机械狼一起），请统一意见刀人 | 狼队选刀口，机械狼只看 |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 救 / 毒 |
| 4 | 女巫请闭眼。通灵师请睁眼，你要查验谁？ | 法官展示身份牌 |
| 5 | 通灵师请闭眼。机械狼请睁眼，（有继承技能时）请发动你的技能 | 按继承的技能行动 |
| 6 | 机械狼请闭眼。猎人请睁眼，确认开枪状态 | |
| 7 | 猎人请闭眼。天亮了 | |

机械狼单独步每晚都念（没技能时也念，零场外）。继承守卫时它的守护也在这一步，**位于狼刀之后**——所以机械狼守的人挡不住当晚的狼刀吗？⚠️ 本项目定为：机械狼继承的守护对当晚刀口照常生效（结算时统一算），步骤顺序只是念台词的顺序。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 通灵师查机械狼 | 「机械狼」 |
| 通灵师查狼人 | 「狼人」 |
| 通灵师出局 | 机械狼下一晚起可查验具体身份 |
| 女巫出局（解药已用、毒药未用） | 机械狼下一晚起有一瓶毒 |
| 守卫出局 | 机械狼下一晚起可守人 |
| 猎人出局 | 机械狼出局时可开枪 |
| 第二个神职出局 | 机械狼技能不变 |
| 三狼全出局 | 机械狼下一晚起可刀人 |
| 机械狼被毒 | 出局；若继承了猎人也不能开枪 |
| 机械狼守住了狼队的刀口 | 允许（它是狼，但守护照常生效） |

## 6. 特殊判定

- **机械狼继承了通灵师，狼队怎么知道结果**：不能交流，机械狼只能白天暗示。
- **狼队故意刀死己方神职让机械狼继承**：本板没有己方神职，不涉及。
- **通灵师和机械狼都查到了对方**：通灵师报「X 是机械狼」是本板最强信息，狼队通常会优先刀通灵师。
- **只剩机械狼一只狼**：它每晚刀人，再加继承技能，很难抓；好人要在三狼出局前抓住它。

## 7. 电子法官实现要点

- 新增机制 `psychic`：同 `seer` 的步骤结构，`nightInfo.checkResult` 改为角色名；`NightKind.PSYCHIC`，优先级 4。
- 新增机制 `mech_wolf`：`faction = 狼人`、`wolfTeam = true` 但 `canKill = false`（狼队步里只读，不计票）；单独步骤 `MECH`（优先级 4.5），动作集合按 `status_json.inherited`（`psychic` / `witch` / `guard` / `hunter` / 空）动态决定。继承在神职出局钩子里写入（只写第一次）。女巫剩余药量从出局女巫的 `status_json` 拷贝。`aliveWolfTeamKillers == 0` 时狼队步由机械狼投票刀人。
- 预言家查验逻辑要加「`mech_wolf` 报好人」的例外（现有逻辑按 `faction` 报狼人，要在 `Mechanic` 上加 `seerResult` 字段）。
- 这是最复杂的狼方机制，建议在狼美人、石像鬼之后做。

## 8. 变体

- **机械狼白痴**：守卫换白痴。
