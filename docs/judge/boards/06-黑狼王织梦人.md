# 黑狼王织梦人

> 📌 织梦人是本项目的原创角色（夜镇世界观里的钟楼织梦人）：夜里把两个人连进同一个梦，同生共死、互知位置。规则没有外部标准，以本文为准。

## 1. 配置

| 项 | 值 |

## 2. 角色与技能

预言家、女巫、猎人、平民、狼人同 02；黑狼王同 08。

### 织梦人 📌 `dreamweaver`
- 好人神职。每晚（含首夜）选择**两名**存活玩家（不含自己）连梦。
- 当晚两人同生共死：其中一人夜里出局（被刀、被毒），另一人一同出局；都没出局则都存活。
- 天亮后两人各自得知「昨晚你和 X 号在同一个梦里」（只知道座位号，不知道身份）。这是织梦人给好人传信息的方式。
- 连梦只持续当晚，天亮解除；白天放逐不触发同生共死。
- 不能连续两晚连同一对；可以换掉其中一人。
- 织梦人自己夜里出局，当晚的连梦照常生效。
- 连坐出局者：没有出局技能（猎人被连坐不能开枪）；可以移交警徽；夜间出局无遗言。
- 没有出局技能。

设计意图：织梦人等于每晚给两个人「绑定」，狼队刀其中一个就会双死；好人用它验人（把疑狼和确认好人绑在一起，狼不敢刀）。⚠️ 平衡性没有实战验证，首批测试后可能要改：候选调整是「只有狼刀触发连坐，女巫毒不触发」。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 织梦人请睁眼，今晚你要把谁和谁连进梦里？ | 选两人 |
| 2 | 织梦人请闭眼。狼人请睁眼（黑狼王一起），请统一意见刀人 | 选刀口 |
| 3 | 狼人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 救 / 毒 |
| 4 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 查 |
| 5 | 预言家请闭眼。猎人请睁眼，确认开枪状态 | |
| 6 | 猎人请闭眼。狼王请睁眼，确认开枪状态 | |
| 7 | 狼王请闭眼。天亮了 | |

织梦人在最前面：连梦要在刀之前定下，不能看到刀口再连。女巫被告知的刀口是狼刀的那个人，不包括连坐者。

## 4. 白天流程

同 README。天亮公布时连坐者一起公布：「昨晚 X 号、Y 号出局」，不说明哪个是刀口。连梦双方各自在手机上看到对方座位（电子法官私信）；线下由法官天亮后分别轻拍告知。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 连 A–B，刀 A | A、B 出局 |
| 连 A–B，刀 A，女巫救 A | A 存活，B 存活 |
| 连 A–B，刀 A，女巫毒 B | A、B 出局（B 被毒也触发 A 连坐，反正 A 已被刀） |
| 连 A–B，刀 C，毒 B | C、B、A 出局（毒触发连坐，见 ⚠️） |
| 连 A–B，A 是猎人被刀 | A 可开枪，B 连坐不能开枪 |
| 连 A–B，B 是狼人 | 狼队刀 A 时 B 也死；狼队一般不知道谁被连了 |
| 连 A–狼王，狼王被刀（自刀） | A 连坐出局，狼王可开枪 |
| 织梦人被刀，当晚连 A–B | 连梦照常生效 |
| 连梦双方白天被放逐 | 不触发连坐 |

## 6. 特殊判定

- **织梦人能不能连狼**：可以，它不知道谁是狼。
- **连梦信息能不能当查验用**：双方只知道「和谁在一个梦里」，不知道阵营；但「我和 X 连梦，X 没死，说明狼没刀我们俩」这类推理是本板核心。
- **同一晚守卫（同类板）守了连梦者之一**：守住的人不死，另一人也不死。
- **狼队刀连梦者，女巫救了，另一人也活**：是。

## 7. 电子法官实现要点

- 新增机制 `dreamweaver`：步骤 `DREAM_LINK`，优先级 0（最前），动作 `link`（`targetSeatNos` 两个）、`none`；校验两人不同、不含自己、不能和上一晚同一对（`status_json.lastLink`）。
- `NightResolver` 结算后增加一步「连坐」：夜间出局名单里含连梦任一方 → 另一方加入出局名单，`cause = linked`（跳过出局技能，允许移交警徽），然后重新判胜负。
- `nightInfo`：织梦人本人 `linkedSeats`；天亮后连梦双方的 `dayInfo` 多一个 `dreamPartnerSeat`（只给本人）。
- 公告不区分刀口和连坐。
- 这个角色规则是新定的，先在有法官模式下用几局（法官手动执行上表），再决定是否写进引擎。
