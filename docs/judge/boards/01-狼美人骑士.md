# 狼美人骑士

> 狼美人每晚魅惑一人，自己出局时被魅惑者陪葬；骑士翻牌决斗。好人投狼美人之前要先想清楚谁会跟着走。

## 1. 配置

| 项 | 值 |

## 2. 角色与技能

预言家、女巫、平民、狼人同 02；守卫同 03；骑士同 04。

### 狼美人 🔧 `wolf_beauty`
- 夜里先和狼队一起刀人，然后**单独**再睁眼一次，魅惑一名存活玩家（可以是任何人，包括狼队友；不能是自己）。
- 可以不魅惑。⚠️ 能否连续两晚魅惑同一人：本项目**可以**；变体：有的桌不允许。
- 被魅惑的玩家不知道自己被魅惑。
- 狼美人出局时（任何方式：被放逐、被刀、被毒、被枪、被骑士决斗），**最近一晚**被魅惑的玩家一起出局（殉情）。殉情者：
  - 没有遗言；
  - ⚠️ **不能发动出局技能**：殉情的猎人不能开枪（本项目采用；变体：有的桌允许）；
  - 如果是警长，可以移交警徽（移交不是技能）。
- 魅惑只保留到下一次魅惑：狼美人今晚魅惑了 B，明晚魅惑 C，那之后狼美人出局带走的是 C。狼美人某晚不魅惑，则没有陪葬者。
- 狼美人**不能自爆**。
- 被预言家查验为狼人。
- 狼美人被放逐时殉情在白天发生，殉情者**有遗言**吗？按 README 2.7：白天跟随放逐一起出局的有遗言。⚠️ 变体：网易线上殉情者无遗言。

## 3. 夜间流程

| 步 | 台词 | 做什么 |
|---|---|---|
| 1 | 守卫请睁眼，今晚你要守护谁？ | 守 |
| 2 | 守卫请闭眼。狼人请睁眼（狼美人一起），请统一意见刀人 | 狼队含狼美人选刀口 |
| 3 | 狼人请闭眼。狼美人请睁眼，今晚你要魅惑谁？ | 狼美人单独指人 |
| 4 | 狼美人请闭眼。女巫请睁眼，今晚 X 号倒下了…… | 救 / 毒 |
| 5 | 女巫请闭眼。预言家请睁眼，你要查验谁？ | 查 |
| 6 | 预言家请闭眼。天亮了 | |

狼美人的魅惑步在女巫之前：女巫用毒毒死狼美人时，当晚的魅惑已经生效，被魅惑者天亮跟着出局。

## 4. 白天流程

同 README，骑士的决斗同 04。狼美人被放逐时：票型公布 → 宣布「X 号出局」→ 法官查看是狼美人 → 宣布「Y 号被魅惑，一同出局」→ 处理两人的警徽移交 → 遗言（狼美人先，殉情者后）→ 入夜。殉情者的出局技能不处理。

## 5. 结算细则

| 情况 | 结果 |
|---|---|
| 狼美人魅惑 A，狼美人被放逐 | 狼美人、A 出局 |
| 狼美人魅惑 A，女巫当晚毒狼美人 | 天亮狼美人、A 一起出局（A 无遗言，是夜间出局） |
| 狼美人魅惑 A，狼队当晚自刀狼美人 | 同上 |
| 狼美人魅惑守卫，守卫当晚守了狼美人（守卫不知道） | 没影响，守护只防刀 |
| 狼美人魅惑猎人，狼美人被放逐 | 猎人殉情，不能开枪 |
| 狼美人魅惑狼队友 | 允许，狼美人出局时队友一起出局 |
| 狼美人魅惑 A，之后一晚没魅惑 | A 不再是被魅惑者，狼美人出局无人殉情 |
| 骑士决斗狼美人 | 狼美人出局，殉情者一起出局，直接入夜 |
| 狼美人是最后一只狼，被放逐并带走最后一个神职 | 同一次出局同时达成 → 狼人胜 |
| 狼美人魅惑了白痴，狼美人被放逐 | 白痴殉情出局，不能翻牌 |

## 6. 特殊判定

- **首夜狼美人魅惑的人当晚被狼队刀死**：魅惑对象已出局，等于没魅惑；第二晚重新魅惑。
- **狼美人魅惑了警长，狼美人被放逐**：警长殉情出局前先移交警徽。
- **被魅惑者在白天被放逐出局了，狼美人之后出局**：没有陪葬者（除非当晚又魅惑了别人）。
- **狼美人被放逐，殉情者是预言家**：预言家没有出局技能，直接出局，有遗言（白天）。
- **狼美人能不能魅惑自己**：不能。

- 新增机制 `wolf_beauty`：狼队成员（`NightKind.WOLF`，优先级 2）**外加**一个单独夜间步骤 `CHARM`（优先级 2.5，在狼队之后、女巫之前），动作 `charm` / `none`，`targetSeatNo` 不能是自己；`status_json.charmedSeat` 每晚覆盖（不魅惑则清空）。

- `nightInfo`：狼美人本人多一个 `charmedSeat`；被魅惑者**不下发任何信息**。
- 夜间顺序校验要加一条：狼美人的魅惑步在女巫之前。
- 公告：「X 号出局」「Y 号被魅惑，一同出局」。对局记录里殉情单独记一条。
- 和骑士（见 04）一起登记后本板变 full。
