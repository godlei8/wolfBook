# 通用流程（所有板子一样）

> 一场狼人杀从建房到复盘的通用流程，和所有角色共用的规则。角色自己的规则在 [roles/](roles/README.md)，板子文件（01、03、08…）只写阵容、夜间顺序和板子专属配置的取值。
> 只写最新的规则，不记改动。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

## 0. 总览

```
对局
├─ 1 房间配置            建房、入座、准备
├─ 2 身份分配            开局随机发牌
├─ 3 夜晚
│   ├─ 夜间步骤[k]       按板子的夜间顺序一步一步走
│   └─ 夜晚结算          全部步骤走完统一结算
├─ 4 警长竞选            只有第一天，房间开了上警才有
├─ 5 天亮播报            公布昨夜死讯，第一夜死的人留遗言
├─ 6 白天发言            顺序发言
├─ 7 放逐投票
│   ├─ 收票 → 计票 → 票型公布
│   └─ 平票 PK           最多一轮
├─ 8 放逐结算
├─ 9 连锁技能            任何人出局都会插进来，处理完回到原处
├─ 10 胜负判定           每次有人出局后都判一次
└─ 11 对局结束与复盘
```

第 3 ~ 8 步每天循环一次，直到第 10 步判出胜负。第 9、10 步不在主线上，哪里有人出局就插在哪里。

| 本文 | 引擎阶段名 |
|---|---|
| 房间配置 | `lobby` |
| 夜晚 | `night_action`（`night_step` 0..n-1） |
| 警长竞选 | `sheriff_signup` → `sheriff_speech` → `sheriff_vote` → `sheriff_pk` |
| 天亮播报 | `day_announce` |
| 白天发言 | `day_speech` |
| 放逐投票 | `exile_vote` → `vote_result` → `vote_pk` → `vote_result` |
| 连锁技能 | `skill_pending` |
| 对局结束 | `finished` |

## 1. 房间配置

- 房主选板子、选模式建房，得到 4 位房号；其他人凭房号或分享入座、点准备。
- **解散、离开、请离**（只在大厅里，开局后都不行）：房主可以解散房间，解散后系统里不再有这个房间，房间里的人都退出；玩家可以自己离开，座位空出来，还能再进；房主可以请人离开，被请离的人不能再进这个房间。房主不能离开，只能解散。
- **两种模式**：有法官（房主就是法官，不入座、不拿牌）和无法官（房主坐 1 号拿牌）。两种模式走同一套自动流程。无法官只能选全部角色都有机制的板子。
- **通用配置项**（节奏，房主建房时和大厅里可调，开局后不能改）：是否上警、发言时长、警上发言时长、狼队行动时长、单人角色行动时长。
- **板子专属配置项**（跟板子走，房间里改不了）：只在阵容里有对应角色时才有，比如 08 的「弹毒」。
- 胜负条件跟板子走，房间里改不了。

## 2. 身份分配

- 房主点开局，系统随机发身份。板子规则在这一刻拷进房间，之后改板子不影响这一局。
- 每人只能在自己手机上看自己的身份牌。狼人整局都能看到队友是谁；不在狼队里的狼（机械狼人）和狼人互不认识。
- 有法官模式的法官看得到全部身份和夜间行动。

## 3. 夜晚

### 3.1 夜间步骤

- 步骤和先后来自板子文件的「夜间顺序」。阵容里没有的角色不叫。
- 每一步：房主手机播报「X 请睁眼」→ 持有者在自己手机上操作，其他人同一位置是同样大小的「天黑请闭眼」→ 到点播「X 请闭眼」进下一步。
- **零场外**：每一步固定时长，持有者出局、被恐惧、没学、没带刀都照叫照等，假步骤和真步骤一样长；单人步骤交了也等到点。
- **时长**：狼队 60 秒（首夜 90），单人 30 秒，猎人 10 秒，空步 5 秒，梦魇 15 秒。狼队和单人时长是通用配置项，可调。
- 只有房主手机出声，其他手机整夜无声无震动。

### 3.2 狼人那一步

- 每只狼各自选目标，可以空刀、可以自刀。
- 狼人选好目标（或空刀）后有「确定」和「重新选择」两个按钮。所有存活的狼人（包括已经带刀的机械狼人）都点了确定，5 秒后狼人那一步结束；确定后 5 秒内有人点重新选择，就回到原来的总时长继续等。没有全部确定，就按狼人那一步的总时长到点强制结束。
- **刀口**（2026-11-12 用户改定）：这一步结束时按选了目标的狼取多数；票数一样多就在并列的人里随机一个；一个目标都没选算空刀。没选的狼和点了「空刀」的狼都不计票。

### 3.3 夜晚结算

全部步骤走完后统一结算，中途不结算、不公布：

- 被刀的人：被守或被救其中一个，不死；同守同救，照死。
- 被毒的人：必死，守卫挡不住。
- 一晚可以死多个人，也可以平安夜。
- 结算完判一次胜负（第 10 步）。死讯留到天亮播报再公布，公布之前死者照常参加警长竞选。

## 4. 警长竞选（只有第一天）

房间开了上警才有，在公布昨夜死讯**之前**进行。

1. **报名**：每人在手机上选上警 / 不上警，20 秒，超时算不上警。别人选了什么不显示，截止后一次公告上警名单。没人上或全员上，警徽流失；只有一人，直接当选。
2. **警上发言**：随机起点和方向，按人计时。警上玩家可以退水。
3. **投票**：只有警下的人投，退水的人不能投，可以弃票，30 秒。
4. **平票 PK**：平票者再各说一轮（先发言的后发言），警下的人加上其余还在警上、不在 PK 的人再投一次；再平，警徽流失。

- 警长放逐投票算 1.5 票，决定白天的发言顺序；出局时可以移交警徽或撕掉。没有单独的归票环节。
- **双爆吞警徽**：警上发言时有狼自爆，第一次竞选推迟到第二天（原来报名、没退水、还活着的人接着选，不重新报名），第二次警徽流失。

## 5. 天亮播报

- 公告昨夜死讯：「昨夜 X 号、Y 号出局」或「昨夜平安夜」，不说死因。
- 死者这时才真正出局，每人依次进连锁技能（第 9 步），全部处理完再往下。
- 第一夜死的人留遗言（见第 12 节「遗言」）。

## 6. 白天发言

- **发言顺序**：有警长由警长选警左 / 警右，有死者时还可以选死左 / 死右；没警长时有死者按死左，没死者随机起点和方向。
- 房主点「开始发言」。按人计时：默认 120 秒，警长 150 秒；到点只提示，不强制换人。发言人自己或房主点下一位。
- 发言时只提示方向（警左 / 警右 / 死左 / 死右，随机时说从几号开始），不列整个发言顺序。
- 所有存活玩家发完言，自动进入放逐投票。
- 没有自由讨论环节。

## 7. 放逐投票

1. **收票**：活着且有投票权的人各自在手机上投，可以弃票，投了不能改。30 秒，到点或全员投完就结算，没投的算弃票。
2. **计票**：警长 1.5 票，其余 1 票。最高票唯一，放逐；全员弃票，无人出局。
3. **票型公布**：全场看到每人投给了谁、各人得票、谁出局。房主点「继续」。
4. **平票 PK**：平票者各说一轮（先发言的后发言），平票者以外的人再投一次，只能投平票者；再平，无人放逐。

## 8. 放逐结算

- 被放逐的人出局，进连锁技能（第 9 步），然后判胜负；被放逐的人有遗言。
- 白痴被放逐照样出局，出局时翻牌公开身份。
- 处理完进入下一个夜晚。

## 9. 连锁技能

任何人出局（夜里死、被放逐、被开枪带走、被点杀）都先插进这一步，处理完回到原来的地方。

- **每个出局者都问一次「是否发动技能」**，15 秒，公告和倒计时都一样。没有技能或不能发动的人手机上只有「确认」，照样等满（零场外）。
- **开枪**（猎人、狼王）：选了发动再选目标，20 秒，超时算不开枪。可以带走任何一名活着的玩家，不能带走自己。公告统一「X 号发动技能，带走了 Y 号」，不翻牌。
- **移交警徽**：出局的警长选移交给谁或撕掉，30 秒，超时算撕掉。
- **连锁**：被带走的人再进这一步（又是猎人、又是警长都照常处理）。同一个人既能开枪又是警长，先开枪、再留遗言（有遗言的话）、最后移交警徽。
- 自爆的人不问技能、不能开枪，是警长时照常移交警徽。
- 对局已经结束，剩下没处理的一律作废。

## 10. 胜负判定

每次有人出局后都判一次，达成马上结束。

- **屠边**：神民全部出局，或平民全部出局，狼人胜；狼人阵营全部出局，好人胜。
- 同一次出局里双方同时达成，算狼人胜。
- 游戏先结束，最后出局的猎人 / 狼王不能开枪。
- **最后一只狼自爆**：当场判好人胜，不进夜晚。

## 11. 对局结束与复盘

- 公告胜方和原因。结果页全场公开每个人的身份，以及历次夜晚的全部行动。
- 对局记录保留整局的公开事件（死讯、票型、技能、自爆），不记发言顺序；结束后加上每晚的行动和每个出局者的死因（被刀、同守同救、破盾刀、被毒、毒被弹回）。可以按天看，也可以按人看每个人的经历。
- 复盘只有结果页和对局记录。

## 12. 贯穿全程

### 遗言

- 每人 120 秒，自爆的狼 60 秒。
- 第一夜死的人有遗言，不管怎么死的（被刀、被毒、同守同救）。
- 白天出局的人都有遗言：被放逐、被开枪带走等。
- 第二夜起，夜里死的人没有遗言。
- 自爆的狼有遗言。
- 被法官点杀的人没有遗言。
- 多人同时有遗言，先后随机。
- 顺序：先开枪，再留遗言，最后移交警徽。

### 狼人自爆

- 警长竞选投票前，或放逐投票开始前，任意时刻可以自爆。
- 自爆的狼当场出局，不参与当晚点刀，有 60 秒遗言。
- 自爆后跳过白天剩余的发言和投票，直接天黑。
- 两名狼人在警长竞选投票前自爆，警徽流失。
- 能自爆的只有狼人和狼王；狼王自爆后不能开枪。

### 法官（只有有法官模式）

- 对局中只能做两件事：暂停 / 继续计时，点杀违规玩家。
- 点杀走正常出局流程，公告注明法官判罚；被点杀的人不能开枪，没有遗言。
- 白天的推进（开始发言、继续、天黑）一直归房主，房主出局后照旧。
