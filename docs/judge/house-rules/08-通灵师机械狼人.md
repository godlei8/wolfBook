# 08 通灵师机械狼人

> 只写阵容、夜间顺序和板子专属配置的取值。角色规则见 [roles/](roles/README.md)，通用流程见 [00-通用流程.md](00-通用流程.md)。

## 阵容

平民 ×4、通灵师、女巫、猎人、守卫、狼人 ×3、机械狼人

## 夜间顺序

| 步 | 角色 | 做什么 |
|---|---|---|
| 1 | 机械狼人 | 没学过：选一人学习，告知对方身份。学过：第二晚起先告知是否带刀，再用学到的技能 |
| 2 | 守卫 | 守一人 |
| 3 | 狼人 | 刀人；狼人全死后，带刀的机械狼人在这一步选普通刀口 |
| 4 | 女巫 | 只看到普通刀的刀口；救、毒或不用 |
| 5 | 通灵师 | 验一人，报具体身份 |
| 6 | 猎人 | 看能不能开枪 |

## 板子配置

- **弹毒**（[机械狼人](roles/机械狼人.md)的专属配置）：默认不开，后台板子编辑页可以打开。
