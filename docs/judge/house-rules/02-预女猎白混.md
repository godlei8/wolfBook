# 02 预女猎白混

## 阵容

平民 ×3、混血儿、预言家、女巫、猎人、白痴、狼人 ×4

## 夜间顺序

| 步 | 角色 | 做什么 |
|---|---|---|
| 1 | 混血儿（仅首夜） | 选除自己外的一名玩家当榜样，不告知榜样的阵营 |
| 2 | 狼人 | 刀人 |
| 3 | 女巫 | 看刀口；救、毒或不用 |
| 4 | 预言家 | 验一人 |
| 5 | 猎人 | 看能不能开枪 |
| 6 | 白痴 | 空步 |

## 板子配置
