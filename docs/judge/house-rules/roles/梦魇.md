# 梦魇

> 角色在哪个板子里规则都一样。通用流程（计时、零场外、自爆、遗言、胜负、夜里怎么一起结算）见 [00-通用流程.md](../00-通用流程.md)。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

- **阵营**：狼人
- **机制**：引擎还没有

## 规则

- 每晚最先睁眼恐惧一人（15 秒），之后和狼人一起睁眼刀人。不能连续两晚恐惧同一人。
- 恐惧到预言家：当晚不能验人。
- 恐惧到女巫：当晚看不到刀口，不能用药。
- 恐惧到守卫：当晚不能守护。
- 恐惧到猎人：当晚被刀或当日被放逐都不能开枪。
- 恐惧到狼人：狼人阵营当晚不能刀人。
- 恐惧到平民：没有效果。
- 被恐惧的角色在自己那一步照常叫醒，告知今晚不能发动技能，时长不变。

## 待拍板

- 梦魇能不能恐惧自己（JY 是不能）。
- 梦魇能不能自爆、能不能自刀（JY 是都能）。
- 双药都用完的女巫被恐惧时，要不要告知她被恐惧。
