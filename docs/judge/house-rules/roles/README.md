# 角色规则

一个角色一个文件。角色的规则跟着角色走，在哪个板子里都一样；板子文件只写阵容、夜间顺序和板子专属配置的取值。
两个角色之间的互动，写在引入这个互动的那个角色文件里（比如「守卫和学到守卫的机械狼人守同一人」写在机械狼人里）。
加新角色：加一个角色文件 + 一个机制（`service/judge/Mechanic`）+ 它的测试，不动板子、不动别的角色。
