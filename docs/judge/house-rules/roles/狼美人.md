# 狼美人

> 角色在哪个板子里规则都一样。通用流程（计时、零场外、自爆、遗言、胜负、夜里怎么一起结算）见 [00-通用流程.md](../00-通用流程.md)。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

- **阵营**：狼人
- **机制**：引擎还没有

## 规则

- 和狼人互相认识。每晚和狼人一起刀人，之后单独睁眼魅惑一人，被魅惑的人不知情。
- 狼美人当晚或当日死亡，被魅惑的人随之殉情。殉情的猎人不能开枪。
- 不能自刀，不能自爆。
- 守卫的守护不影响魅惑。

## 待拍板

- 被骑士决斗死的狼美人，被魅惑的人殉不殉情（按「当日死亡」是殉情，JY 是决斗死魅惑失效）。
- 狼美人能不能连续两晚魅惑同一人（JY 是不能）。
