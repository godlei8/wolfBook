# 机械狼人

> 角色在哪个板子里规则都一样。通用流程（计时、零场外、自爆、遗言、胜负、夜里怎么一起结算）见 [00-通用流程.md](../00-通用流程.md)。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

- **阵营**：狼人
- **机制**：`mech_wolf`

## 规则

- 和狼人互不认识。每晚最先单独睁眼。不能自爆。
- **学习**：整局一次，任意一晚选一名玩家，学到对方身份的技能。学到的技能下一晚起能用；学到猎人，学习当晚起出局就能开枪。
- **带刀**：狼人在时不带刀；狼人全部死亡后带刀，每晚一刀普通刀。第二晚起每晚睁眼先告知是否带刀。
- **在哪一步用**：普通刀口在狼人那一步选，和狼人一样确定 / 重新选择；学到的技能（查验、毒、守护、破盾刀）都在机械狼人那一步用。
- **被通灵师验**：没学过报机械狼人，学过报学到的身份。

**学到的技能**

- **通灵师**：每晚验一人的具体身份。
- **女巫**：固定一瓶毒药，没有解药。女巫看不到它的毒口、救不了；守卫挡不住；猎人被它毒不能开枪。
- **猎人**：开枪规则同猎人。
- **守卫**：每晚守一人，可以自守、空守，不能连守；挡狼刀，同守同救照死。和守卫守同一人，两个守护都生效。还能挡毒，见下面「弹毒」。
- **狼人**：带刀后多一刀破盾刀。两刀可以只出一刀，也可以打同一人。破盾刀无视所有守护，女巫看不到它的目标；两刀打同一人时女巫用解药，解药耗掉、人照死。
- **平民**，或者一直没学：没有额外技能。

**弹毒**（板子专属配置，默认不开，在板子里设）

- 不开：被学到守卫的机械狼人守护的人中毒不死。
- 开：毒反弹给下毒的人，被守的人不死，下毒的人被毒死。弹回去的毒守卫挡不住；女巫被弹毒而死算被毒杀。
