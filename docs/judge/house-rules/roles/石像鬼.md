# 石像鬼

> 角色在哪个板子里规则都一样。通用流程（计时、零场外、自爆、遗言、胜负、夜里怎么一起结算）见 [00-通用流程.md](../00-通用流程.md)。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

- **阵营**：狼人
- **机制**：引擎还没有

## 规则

- 和狼人互不认识。每晚在狼人之后单独睁眼，验一人的具体身份。
- 狼人在时不带刀；狼人全部死亡后带刀，先验人再刀一人。女巫照常看到刀口。
- 预言家验石像鬼报狼人。

## 待拍板

- 石像鬼能不能自爆（JY 是不能）。
- 石像鬼能不能验自己、能不能重复验同一人（JY 是都不能）。
