# 混血儿

> 角色在哪个板子里规则都一样。通用流程（计时、零场外、自爆、遗言、胜负、夜里怎么一起结算）见 [00-通用流程.md](../00-通用流程.md)。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

- **阵营**：好人 · 平民
- **机制**：引擎还没有

## 规则

- 第一夜选除自己外的一名玩家当榜样，不告知榜样的阵营。
- 榜样是好人阵营，混血儿是好人混，胜利条件同好人；榜样是狼人阵营，是狼混，胜利条件同狼人。
- 狼混不入狼队，和狼人互不认识。

## 待拍板

- 预言家验混血儿报什么（JY 是始终报好人）。
- 屠边时混血儿算不算平民；狼混是否要被刀掉狼人才算屠民。
- 榜样中途死亡，混血儿胜负是否不变。
- 混血儿首夜超时不选怎么办（JY 是随机选一人）。
