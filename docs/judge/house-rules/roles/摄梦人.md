# 摄梦人

> 角色在哪个板子里规则都一样。通用流程（计时、零场外、自爆、遗言、胜负、夜里怎么一起结算）见 [00-通用流程.md](../00-通用流程.md)。没写的细节列在「待拍板」，问用户定，不按 JY / 网易 / 记忆补。

- **阵营**：好人 · 神民
- **机制**：引擎还没有

## 规则

- 每晚摄梦一人，被摄的人当晚成为梦游者。
- 狼人刀梦游者，视为空刀。
- 女巫对梦游者用毒药或解药，药浪费，算用掉。
- 摄梦人夜里死亡，或连续两晚摄梦同一人，梦游者被摄梦而死。
- 狼王被摄梦而死不能开枪。

## 待拍板

- 摄梦人能不能摄自己、能不能不摄、超时怎么办（JY 是不能摄自己、必须摄、超时随机）。
- 狼刀到梦游者时，女巫看到的是狼指的号码还是空刀（JY 是照报狼指的号码）。
- 猎人被摄梦而死能不能开枪（JY 是不能）。
