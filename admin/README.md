# Wolfbook Admin

狼人杀内容平台管理后台，基于 `Vue 3 + TypeScript + Vite + Element Plus`。

## 常用命令

```powershell
npm install
npm run dev
npm run build
```

默认开发地址：

- `http://localhost:5173`

## 环境变量

可通过 `VITE_API_BASE_URL` 指向后端接口根地址；未配置时，开发环境默认请求：

- `http://localhost:8080`

## 主要功能

- 后台登录
- 板子管理
- 角色管理
- 社区治理
- AI 助手配置、知识库、发布与日志管理
